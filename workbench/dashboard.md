## 当前快速记忆区

### 资料分析

```text
基期量 = 现期量 / (1+r)
增长量 = 现期量 × r / (1+r)
现期比重 = 部分 / 整体
基期比重 = 现期比重 × (1+整体r)/(1+部分r)
部分增速 > 整体增速 → 比重上升
间隔增长率 = r1+r2+r1r2
```

速算原则：**先看选项差距，再决定精度；能比较不精算；主体/年份/单位同时核对。**

### 判断推理

```text
如果A→B，则逆否：¬B→¬A
只有A才B：B→A
三词类比：A-B / B-C / A-C 至少两层核对
定义：主体/客体/条件/方式/目的/结果/范围
分析推理：多条件就落表/枚举，不纯脑推
论证：论据 → 缺失桥梁 → 结论；相关性先于力度
```

### 数量关系

```text
先问：能代入吗？有整除/奇偶吗？能赋值吗？是高频模型吗？能方程吗？
工程：总量=效率×时间
行程：S=vt
利润：售价=成本×(1+利润率)
独立事件同时发生：概率相乘
至少一次：1-一次都没有
顺序重要→排列；不重要→组合
```

当前数量的关键不是多学公式，而是训练：**15–30秒内识别模型与是否值得继续做。**
