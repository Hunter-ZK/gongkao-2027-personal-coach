# 工作台全流程运行手册

本仓库是长期备考工作台，不是静态资料库。所有训练结果、错题、方法、计划和复盘都通过同一条流水线维护。

## 1. 输入端

用户只需提供以下任一内容：
- 成绩截图 / PDF / 导出记录；
- 单题或错题截图；
- 申论材料 + 作答；
- “今天学什么”；
- “收工”；
- 老师/课程/方法研究请求；
- 选岗研究请求。

原则：能从截图或文件提取的数据，不要求用户重复手填。

## 2. 行测训练流水线

`原始结果 → 识别考试/模块 → 提取题数/正确数/用时 → 写 training-log → 逐题归类 → 判断是否形成结构性错误 → 更新 error-patterns → 提取候选方法 → 新题验证 → 更新 methods → 更新 Dashboard → 调整下一任务`

### 错题不是全部长期存档
只有以下情况进入长期错误模式：
- 重复出现；
- 明显知识/方法缺口；
- 做对但严重超时；
- 影响整卷时间结构；
- 高频题型且可形成明确规则。

单次偶发错误先记在训练记录，不立即判为长期弱项。

## 3. 方法论流水线

状态：`候选 → 验证中 → 已采用 / 淘汰`

只有经过真实题验证的方法才能进入 `progress/personal-methodology.md`。

最终表达必须能压缩成：

> 看到 X → 先做 Y → 若出现 Z 则切换/放弃。

## 4. 申论流水线

`材料 → 作答 → 回到材料逐段找依据 → 漏点/错分层/表达问题 → 规范表达 → 写入训练记录 → 高频表达进入 expression-bank → 后续同类材料验证`

任何分数均为训练估分，不冒充官方评分。

## 5. 每日运行

### 开工
读取：
1. `progress/current_state.md`
2. 最新 `plans/daily/`
3. `data/error-patterns.csv` 中“新发现/修复中”项目
4. 最近训练记录

输出保底/标准/加量任务。

### 收工
自动生成：
- 完成 / 未完成；
- P0完成率；
- 有效题量；
- 正确率/用时变化；
- 新错误模式；
- 修复中的错误；
- 今日最有价值提升；
- 明日调整。

并同步更新 Dashboard 和次日计划。

## 6. 每周运行

每7天或用户主动要求时：
- 统计投入时间与有效题量；
- 看7日模块正确率/用时趋势；
- 统计错误复发率；
- 删除无效训练任务；
- 确认下周三个最高优先级目标；
- 判断是否满足阶段升级条件。

## 7. 阶段升级

不机械按日期升级。主要看：
- 正确率；
- 限时完成度；
- 连续稳定性；
- 错误复发率；
- 整卷完成度；
- 申论材料覆盖和限时写作能力。

默认路径：
`基线 → 快速恢复 → 高频专项 → 时间压缩 → 专项/整卷交替 → 国考全真 → 国考后迁移广东 → 广东全真`

## 8. 文件职责

| 路径 | 作用 |
|---|---|
| `workbench/dashboard.md` | 一屏看当前状态与下一步 |
| `progress/current_state.md` | 阶段事实与决策基线 |
| `plans/daily/` | 每日具体任务 |
| `data/training-log.csv` | 训练主表 |
| `records/` | 单次训练详细记录 |
| `data/error-patterns.csv` | 结构性错误模式 |
| `data/methods.csv` | 候选/验证方法 |
| `progress/personal-methodology.md` | 已验证个人考场方法 |
| `progress/shenlun-expression-bank.md` | 已验证申论规范表达 |
| `data/research-log.csv` | 老师/课程/外部方法研究 |
| `reviews/weekly/` | 周复盘 |
| `evidence/` | 原始截图/PDF的索引或归档 |

## 9. 数据质量规则

- 不从缺失信息猜用时；
- 不因单次2–5题小样本就断言整个模块强弱；
- 不从错误选项臆测用户真实思路，除非用户说明或过程证据足够；
- 训练卷来源/年份不明确时明确标注“未标注”；
- 任何当前考试规则变化必须重新核验官方来源。
