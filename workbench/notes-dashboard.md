## 2. 笔记版本规则

每条方法使用四级状态：

- `候选`：来自旧笔记/老师/社区/Skill，尚未个人验证；
- `可用`：逻辑与数学上成立，已通过少量真题；
- `个人稳定`：连续多组真题有效，适合本人；
- `淘汰/限制`：只适合特殊条件、容易误用，或个人使用收益低。

任何“秒杀法”“固定顺序”“固定时间”“答案分布蒙题法”默认只能进入**候选**，不得直接进入个人稳定方法。

## 3. 资料分析知识树

### 3.1 必须恢复

`概念识别 → ABRX → 基期/现期 → 增长率/增长量 → 比重 → 平均数 → 倍数 → 年均/间隔 → 综合判断`

### 3.2 计算工具箱

- 截位直除：先看选项差距再决定精度；
- 分数/百分数互换：用于快速估算；
- 份数思维：用于增长量、基期等场景；
- 比较优先：能定性/比较时不精算；
- 高位/尾数/差分等方法：必须标明选项结构和误差条件。

### 3.3 外部学习启发

公开课程整理者常把资料拆成“速算、ABRX、比重、比较、平均倍数、特殊考点”等板块，优点是**按识别场景组织**，比纯公式表更适合恢复。当前笔记采用“题型识别 → 公式 → 速算条件 → 易错点 → 真题验证”结构。

进一步的学员/名师实战提炼见：[07-名师与学员实战补充](../notes/xingce/07-名师与学员实战补充.md)。

## 4. 判断推理知识树

### 图形推理

`位置 → 样式 → 属性 → 数量(点线角面素) → 特殊元素 → 空间`

注意：不是机械从第一项扫到底，而是先找最显眼特征，再进入对应规则库。

### 定义判断

`主体 / 客体 / 条件 / 方式 / 原因 / 目的 / 结果 / 范围`

### 类比推理

`语义 / 逻辑 / 对应 / 语法 → 方向 → 二级辨析`

三词题必须至少检查两层关系，不能只凭一句“读起来像”。

### 逻辑判断

- 翻译推理：必要/充分、逆否；
- 真假推理：矛盾、反对；
- 分析推理：表格、枚举、代入；
- 论证：论据—桥梁—结论；
- 加强/削弱：相关性优先，再比较力度。

Training-002 的唯一错误已经进入“加强论证相关性”候选错误模式，后续系统恢复后再验证。

## 5. 言语理解知识树

### 中心理解

`问法 → 文段结构 → 主题词 → 中心句/重点 → 选项核对`

重点关注：转折、因果、并列、问题—对策、总分/分总。

### 逻辑填空

`语境关系 → 搭配 → 词义侧重 → 程度/感情色彩/适用对象 → 代入`

### 语句表达

- 排序：首句限制、强捆绑、时间/逻辑顺序；
- 填句：前后话题、句子功能；
- 接语：紧扣尾句话题，不重复前文。

### 学员笔记启发

公开的阿里木江复习型思维导图强调“快速按题型恢复”，说明言语复习更适合做**结构化方法卡+少量真题校正**，而不是重新长时间听基础课。

## 6. 数量关系知识树

### 第一层：先判断值不值得做

`代入? → 整除/奇偶/余数? → 高频模型? → 赋值? → 方程? → 枚举?`

### 第二层：高频模型

工程、行程、利润、浓度、容斥、排列组合、概率、最值、几何、年龄、周期日期等。

### 第三层：个人速度诊断

每题必须逐渐归到：

- `秒识别-快算`
- `识别快-计算慢`
- `识别慢-会做`
- `建模失败`
- `应主动放弃`

当前Training-001/002累计数量4/5，但用户主观明确感到数量更耗时，所以后续重点不是“正确率补到多少”，而是**能否在15–30秒内判断路径和取舍**。
