# 名师 / 社区 / Skill 研究 Dashboard

> 目标：收集真正能转化为“考场动作”的公开方法，不做老师崇拜和课程堆积。

## 1. 来源分级

| 级别 | 来源 | 用途 |
|---|---|---|
| A | 官方考试大纲、法律法规、正式公告 | 考情与制度事实 |
| B | 老师本人公开课程/直播/公开视频 | 方法原始来源 |
| C | 高质量学员笔记、课程整理、复盘 | 发现结构、易错点和学习顺序 |
| D | GitHub Skill / 培训机构知识整理 | 工作流、方法索引、结构参考 |
| E | 零散个人经验帖 | 只能作为候选观点，不直接形成规则 |

## 2. 当前研究对象

### 花生十三

**适合吸收：**

- 资料分析完整方法树；
- ABRX/份数思维；
- 先识别题型和选项差距再决定计算精度；
- 速算方法按适用场景管理；
- 数量的赋值、代入、比例、方程等短路径。

**暂不直接采用：**

- 固定做题顺序；
- 对所有人统一的模块目标时间；
- 任何依赖答案分布的蒙题规则。

### 阿里木江

当前公开课程/学员复习内容更适合用于：

- 言语题型完整地图；
- 中心理解的结构分析；
- 逻辑填空的语境与词义辨析；
- 判断中定义、逻辑、类比的结构化恢复。

对用户的意义：不必完整重听长课，先把课程骨架抽成方法卡，再用真题判断需要补哪一节。

### 陈怀安

当前持续发布国考/省考模考复盘和第一视角做题。价值不是“再学一套基础理论”，而是：

- 看高手如何取舍；
- 同一道题如何选择最短路径；
- 哪些题考场应跳过；
- 模考后如何按模块复盘；
- 观察最新命题/模拟风格变化。

更适合 Phase 1/2，而不是当前把全部内容灌进基础笔记。

### 其他公开老师/社区

不按“谁最强”选老师，而按题型问题选择：

- 图推：优先寻找规律字典清晰、空间题讲解扎实的老师；
- 言语：比较不同老师对中心理解和逻辑填空的实际真题解释力；
- 数量：优先短路径、可稳定复现的方法；
- 资料：优先速算适用条件和误差控制。

## 3. 学员/社区内容怎么采纳

用户明确希望采集“别人听名师后的感受和笔记”。工作台采用三类价值：

1. **课程结构重组**：例如有人把资料课整理为速算、ABRX、比重、平均/倍数等卡片，说明这类知识适合模块化复习；
2. **高频踩坑**：统计多个学习者反复提到的误用点；
3. **学习方式**：哪些内容适合系统听、哪些适合看思维导图快速恢复、哪些必须大量刷题才能形成速度。

不采纳：

- “某老师YYDS”式结论；
- 未给条件的“秒杀必对”；
- 仅凭一次考试分数推荐老师；
- 无法区分真题和模拟题的经验。

重点借鉴：

- 来源分级；

- 制度信息必须来源明确。

## 5. 当前研究结论

目前最适合你的恢复方式不是“选一个老师从头完整听”，而是：

`完整题型地图 → 多来源方法卡 → 旧笔记对照 → 近年真题验证 → 形成个人稳定方法`

原因：你已有旧基础，且两组冷启动已显示资料/判断/数量的多个题型仍能正确调用；重新从零学会浪费大量时间。
