## 5. 2–4天快速恢复建议

这不是死日程；按实际工作时间滚动。

### Block A｜资料分析 70–90min

`系统笔记20–30m → 闭卷回忆5–10m → 真题10–15题25–35m → 复盘10–15m`

### Block B｜判断推理 90–110min

`系统笔记35–45m → 回忆10m → 混合15–20题30–40m → 复盘10–15m`

### Block C｜言语 70–90min

`系统笔记25–35m → 回忆5–10m → 10–15题25–35m → 复盘10m`

### Block D｜数量 80–100min

`系统笔记35–45m → 高频模型回忆10m → 8–10题独立计时30m左右 → 复盘`

重点记录：识别慢 / 建模慢 / 计算慢 / 应放弃。

### Block E｜广东科学推理 60–90min

基础公式与实验逻辑 → 近年广东题验证。

### Block F｜政治/常识 首轮45–60min

稳定框架首轮 + 后续每日滚动。

## 6. 产能管理

按三档管理，不把“工作空档8–10小时”直接等同深度学习时间。

| 档位 | 日有效学习 | 用途 |
|---|---:|---|
| 保底 | 60–90min | 至少完成一个核心Block的一半或一轮小训练 |
| 标准 | 2–3h | 完成1–2个Block + 真题 |
| 加量 | 4h+ | 仅状态良好时使用，不作为每日硬要求 |

## 7. 周规划框架

每周只固定五类产出：

- 行测有效题量；
- 行测模块正确率/速度；
- 申论训练次数与得分点质量；
- 错误模式修复数；
- 个人方法论新增/淘汰数。

周末通过 `reviews/weekly/` 复盘，不以“听了多少小时课”作为主指标。

## 8. 计划调整规则

出现以下情况时主动调整：

- 某模块恢复后连续两组>85%且速度正常 → 减少基础复习，转真题；
- 某题型连续2–3组重复错 → 升级专项；
- 正确率高但时间明显超标 → 转速度专项；
- 学习计划连续2天完成率<70% → 降低任务量，而不是堆积补作业；
- 当年正式公告/大纲变化 → 立即改考试画像和计划。
