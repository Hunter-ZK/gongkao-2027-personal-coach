# 3. 快速记忆卡｜资料分析

## ABRX

```text
B = A(1+R)
A = B/(1+R)
X = B-A = AR
X = B×R/(1+R)
R = X/A = X/(B-X)
```

## 高频比值

```text
现期比重 = 部分/整体
基期比重 = 现期比重 × (1+整体增速)/(1+部分增速)

若部分增速 > 整体增速 → 比重上升
若部分增速 < 整体增速 → 比重下降
```

## 平均数

```text
平均数 = 总量/份数
总量增速 > 份数增速 → 平均数上升
```

## 间隔增长率

```text
R = r1+r2+r1r2
```

## 速算原则

- 选项差距决定精度；
- 能比较不精算；
- 常用分数与百分数互换；
- 先排数量级，再做截位直除；
- 主体、年份、单位必须同时核对。

**本次冷测提醒**：Q11 基期量、Q12 两期比重百分点变化必须重新形成条件反射。

# 4. 快速记忆卡｜判断推理

## 翻译

```text
如果A那么B：A→B
逆否：¬B→¬A

只有A才B：B→A

¬(A且B)=¬A或¬B
¬(A或B)=¬A且¬B
```

## 图推检索

```text
位置 → 样式 → 属性 → 数量（点线角面素）→ 特殊元素 → 空间
```

不是每题机械按顺序扫，先抓最显眼特征。

## 类比

```text
两词：先造最硬关系句
三词：A-B、B-C、A-C 三组都核对
```

## 定义

圈：

```text
主体 / 客体 / 条件 / 方式 / 目的 / 结果 / 范围
```

## 分析推理

- 多人、多位置、多条件 → **落表**；
- 选项给完整方案 → 优先代入；
- 约束最强的人/位置先处理。

## 论证

```text
论据 → 缺失桥梁 → 结论
```

削弱因果常见：因果倒置、另有他因、有因无果、无因有果、实验设计问题。

# 5. 快速记忆卡｜言语理解

## 主旨题

```text
先看问法 → 划结构 → 找中心/主题 → 核对选项
```

重点结构：转折、因果、并列、问题—对策、总分。

### 错项高频

- 偷换主题；
- 范围扩大/缩小；
- 可能→必然；
- 例子当主旨；
- 并列只概括一半。

## 细节题

核对：主体、时间、范围、逻辑关系。

## 排序

```text
首句 → 强捆绑 → 先后关系 → 尾句
```

## 逻辑填空

```text
语境关系 → 固定搭配 → 词义侧重 → 程度/感情色彩/对象
```

不是先凭“哪个词读起来顺”。

# 6. 快速记忆卡｜数量关系

## 做题之前先问

```text
能代入吗？
有整除/奇偶/余数吗？
是高频模型吗？
能赋值吗？
一元方程能解决吗？
```

都不是 → 后做。

## 高频基础

```text
工程：总量=效率×时间
行程：S=vt
利润：售价=成本×(1+利润率)
概率：独立事件同时发生→相乘
至少一次：1-一次都没有
排列/组合：顺序重要→排列；不重要→组合
容斥：A∪B=A+B-A∩B
```

## 当前个人重点

数量题不是先追求“全部会做”，而是恢复：

1. **15–30秒识别模型**；
2. 找到最短路径；
3. 复杂题及时止损。

Training-001 仅2题，无法判断整体水平，但已经知道**相对耗时偏高**，后续数量真题必须记录模块总用时。
