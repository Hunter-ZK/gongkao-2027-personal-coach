# 四年前行测笔记索引

这些文件来自用户约四年前的学习积累。定位：**历史方法库/恢复记忆材料，不是当前考试规则来源**。

已有模块：
- 图形推理
- 定义判断
- 类比推理
- 翻译推理
- 逻辑论证
- 言语理解
- 词语积累
- 数量关系
- 资料分析

特点：
- 行测传统模块覆盖较完整；
- 资料、数量、判断方法体系较丰富；
- 缺少当前政治理论模块；
- 申论体系基本缺失；
- 部分题型结构、考试时长、策略可能已过时；
- 原 Markdown 中存在历史图片相对路径，当前包未包含原图片资源。

使用原则：当某一模块需要快速恢复时，先读对应旧笔记，再用近年真题验证和删改；不要从第一页到最后一页重新学习。
