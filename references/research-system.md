# 外部研究系统（老师 / 课程 / B站 / 小红书 / GitHub）

## 目的
研究只服务于解决当前瓶颈，不把“研究怎么学习”变成主要学习活动。

## 渠道
- 官方考试信息；
- B站老师公开内容与高分考生复盘；
- 小红书在职备考/高分复盘（低可信，需要交叉验证）；
- GitHub 公考 Skill/Agent/工作台项目；
- 机构资料仅作为候选方法来源。

## 当前可关注的候选方向（不是背书）
- 花生十三：资料/判断/数量等体系化方法、刷题与套题内容较丰富；更适合抽取方法和专项复盘，不默认要求从头听系统课。
- 陈怀安：当前公开内容中持续做 2027 国考模考分模块复盘，适合作为“模考后对照考场思路”的候选来源。
- 阿里木江：用户过去听过，言语可作为候选方法来源；是否继续使用看真实训练效果。
- 申论候选来源应单独研究，不因行测老师强就延伸认为其申论也强。

## 评估表
每个资源记录：
- 老师/作者
- 平台与链接/标题
- 日期
- 模块
- 主张
- 内容类型（系统课/真题/模考/经验）
- 证据（真题展示/个人高分/仅观点）
- 适配用户的理由
- 风险/样本偏差
- 试验方案
- 结论：候选/试验/采用/淘汰

## 审核规则
- 同一方法最好寻找两个独立来源或与真题规律核对；
- “某人两次 90+”说明个体经验有价值，但不证明普适；
- 评论区和点赞只代表关注度，不代表效果；
- 不推荐盗版付费课程搬运；
- 每周研究预算默认不超过一次集中时段。
