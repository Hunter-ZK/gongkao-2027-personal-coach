**【重难点】**
- 语义关系
- 逻辑关系
- 语法关系
- 对比择优

**【常见题型】**
- 两词型 → A：B
- 三词型 → A：B：C
- 填空型 → A对于（）相当于（）对于B

- 词语的位置关系 → **顺序**
- 词语的逻辑关系 → **造句**

# 1. 语义关系

## 1.1. 近/反/多义关系

**【识别】**
出现成语，优先考虑语义关系。

- 一级辨析
  - 近义：美丽：漂亮；持之以恒：坚持不懈
  - 反义：勇敢：懦弱；言而有信：言而无信
  - 多义：长：长度：各有所长
- 二级辨析
  - 感情色彩：爱好：嗜好
  - 程度轻重：干净：一尘不染

## 1.2. 比喻象征义
- 比喻义：造句→像。兄弟：手足；月亮：玉盘
- 象征义：造句→象征。玫瑰：爱情；荷花：高洁

# 2. 集合关系

## 2.1. 全同关系
- 造句：A就是B
- 二级辨析：古今、中外、雅俗、别称、自他

## 2.2. 并列关系
- 矛盾关系：非A即B，造句“除了A就是B”
- 反对关系：存在其他类别，造句“除了A不只是B”
- 二级辨析：天然/人工、时间先后、命名方式、供能方式等

## 2.3. 包容关系
- 种属关系：A是一种B
- 组成关系：A组成B
- 二级辨析：指代、必然/或然组成、位置、天然/人工、零件/成分等

## 2.4. 交叉关系
- 有的A是B，有的A不是B；有的B是A，有的B不是A
- 常见出题：尾缀一样、出现社会属性

# 3. 对应关系

- 时间：先A，后B；辨析主体是否一致、结果好坏
- 因果：因为A，所以B；辨析自然/人为、必然/或然、积极/消极
- 目的与方式：为了达到A，做了B；辨析方式是否能达目的
- 原材料：制造A的原材料是B；辨析物理/化学变化、直接/间接材料
- 功能：A是用来B的；辨析主要/次要功能
- 属性与特点：A有B属性/特点；辨析必然/或然属性
- 条件：充分条件“A了就一定B”；必要条件“没A一定就没B”
- 根据：A根据B来决定
- 职业：职业A的职责/服务对象/工作场所/工具是B

# 4. 语法关系

**【题型特征】**
- 两词没有明显逻辑关系
- 完整成语被拆分
- 反复出现相同字

**【理论要点】**
拆分 → 看词性 → 看词义

**【词性】**
- 名词
- 动词
- 形容词

**【句子结构】**
- 主谓：名词+动词
- 动宾：动词+名词
- 主宾：名词+动词+名词
- 偏正：形容词+的/地+动词
