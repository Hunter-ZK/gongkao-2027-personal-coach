# 个人方法论系统

## 定义
方法论不是完整笔记，而是“考场决策手册”。

每条正式方法必须写成：
`适用考试｜模块/题型｜触发信号｜第一动作｜核心步骤｜止损条件｜验证数据｜状态`

## 四层结构
1. 整卷：顺序、时间锚点、跳题、涂卡；
2. 模块：资料/判断/言语/数量/政治常识/申论；
3. 子题型：看到 X 如何处理；
4. 红线：用户个人最容易犯的错误。

## 状态
候选 → 试验中 → 已采用 → 淘汰。

任何老师、旧笔记、AI 建议都只能先进入候选。至少经过真实训练验证后才能进入“已采用”。

## 完整笔记与方法论分离
用户希望形成一版完整笔记：
- 《知识笔记》保存公式、题型、系统知识；
- 《方法论》只保存上场动作。
两者不可混成一本越来越长、考前无法翻的文档。
