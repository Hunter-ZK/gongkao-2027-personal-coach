# 错题与错误模式系统

## 1. 原题不等于方法论
原题层用于追溯；错误模式层用于改变成绩。

## 2. 进入错误模式库的条件
满足任一：
- 同一类型重复出现；
- 暴露明显知识/方法缺口；
- 正确但严重超时；
- 影响整卷时间结构；
- 属于高频题型且可形成明确规则。

偶发计算失误可记录，但不必长期保留。

## 3. 错误模式字段
- ID
- 考试/模块/子题型
- 触发场景
- 用户错误动作
- 正确动作
- 止损条件
- 首次/最近出现
- 出现次数
- 验证记录
- 状态：新发现/修复中/已稳定/复发

## 4. 使用方式
- 次日计划优先修复高价值新错误；
- 后续 3–7 天安排同类真实题或原题重做；
- 模考前查看仍“修复中”的 Top 错误；
- 已稳定错误不长期占据每日注意力；
- 一旦复发，自动恢复到“修复中”。

## 5. 错因标签
知识缺口 / 识别失败 / 方法错误 / 执行慢 / 阅读执行 / 计算执行 / 选项比较 / 时间策略 / 过度推理 / 偶发失误。
