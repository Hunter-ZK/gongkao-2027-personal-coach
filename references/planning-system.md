# 规划系统

## 1. 时间预算

每周滚动估计三档产能：
- 保底：即使工作较忙仍能完成；
- 标准：正常工作周完成；
- 加量：工作空闲/周末状态好时增加。

工作中的碎片时间优先给可中断任务：政治理论、言语小组、错题规则、词语/规范表达、短复盘。
晚间与周末保留给不可中断任务：整套资料、判断组合、完整行测、申论写作、长复盘。

## 2. 初始阶段

### Phase 0 基线（最短）
目标：回答“现在真实在哪”。
- 一套近年广东行测限时；
- 一套近年国考副省行测限时；
- 一次广东目标类别申论诊断。

### Phase 1 快速恢复
不重新系统听课。根据基线恢复高收益模块，旧笔记只作为索引。

### Phase 2 专项提分 + 时间压缩
以真实题为主，专项正确率和用时必须一起达标。

### Phase 3 专项/整卷交替
每周至少有整卷训练，避免“专项很强、整卷崩盘”。

### Phase 4 国考冲刺
切换国考副省节奏与申论卷型。

### Phase 5 国考后迁移广东
用国考暴露的问题立即调整；重点转入广东 90 分钟策略和广东目标申论类别。

## 3. 日计划模板

### 早间（10–30min）
只做唤醒：方法论卡片、政治理论、昨天 1–2 条错误模式。

### 工作间隙（多个 10–30min）
言语/政治理论/短资料组/错题规则/申论表达。

### 午间或完整空档（30–60min）
限时专项小组。

### 晚间（1.5–3h）
当日核心任务：限时真题、申论、小套/整套、深复盘。

### 周末
整卷 + 深复盘 + 申论完整训练。

## 4. 任务格式

每项任务：
`[P0/P1/P2] 时间段｜材料来源｜题型/卷｜题量｜限时｜完成标准｜复盘动作`

## 5. 调整规则
- 连续 2 天完成率 < 80%：先查计划是否高估时间，不立即归咎自律。
- 连续 3 次同类训练无提升：改变训练方法或引入针对性课程。
- 正确率高但超时：进入时间压缩，不继续盲刷同难度。
- 模考失分主要来自未做：优先重构整卷策略而不是继续补知识。
