# 行测恢复笔记｜来源与研究地图

> 目的：明确区分用户旧笔记、官方范围、公开课程研究和本仓库重新推导内容，避免把网络老师观点包装成“官方结论”。

## 1. 官方范围

### 广东省考 2026 大纲

确认：

- 行测 90 分钟，100 分；
- 模块包括政治理论、常识应用、言语理解与表达、数量关系、判断推理、资料分析；
- 判断推理包含图形推理、逻辑判断、科学推理等；
- 科学推理要求根据文字或图表信息运用基本科学知识推理。

来源：广东省委组织部 2026 招考公告及公开转载的笔试大纲全文。

### 国考 2026 大纲

确认：

- 行测 120 分钟，100 分；
- 模块包括政治理论、常识判断、言语理解与表达、数量关系、判断推理、资料分析。

来源：2026 年度中央机关及其直属机构考试录用公务员公共科目笔试考试大纲公开政府转载页。

## 2. 用户旧笔记

本轮重点沿用其**架构与已验证过的个人记忆入口**，而非无条件接受所有公式/逻辑记号。

旧笔记覆盖：

- 资料分析：阅读、速算、ABRX、比重、平均、倍数、特殊增长率、陷阱；
- 判断：图形、定义、类比、翻译推理、逻辑论证；
- 言语：片段阅读、语句表达、逻辑填空；
- 数量：代入、数特、方程、工程、行程、利润、最值、排列组合、概率、容斥、浓度、几何等。

审计发现的明显逻辑记号问题见 `references/legacy-note-audit.md`。

## 3. 网络公开课程研究

### 花生十三

公开课程目录显示其资料分析体系重点包含：

- 加减乘除速算；
- ABRX 四量关系；
- 份数法/假设分配；
- 比重、平均、倍数；
- 图形推理的定性、定量、位置、叠加、立体等。

本仓库采用其“先建立关系、再速算”的课程结构思想，但不复制付费讲义或未公开内容。

### 阿里木江

公开系统课目录覆盖：

- 言语理解完整系统；
- 判断中的类比、定义、翻译、真假、集合、组合排列、论证、图形等。

本仓库主要借鉴其“按子题型系统化恢复”的组织方式，不把老师个人口诀视为标准逻辑。

### 刘杰

公开判断推理系统课目录对图推划分较细：

- 位置：旋转/翻转/平移；
- 样式；
- 属性：曲直/开闭/对称；
- 数量：点/线/面/素/角；
- 特殊规律；
- 空间规律；
- 逻辑论证与类比定义。

用于补强图推目录完整性。

### 陈怀安

近年持续公开国考/省考模考复盘，覆盖资料、数量、判断、言语。其价值主要作为**考场实战与模考复盘样本**。本仓库暂不直接采纳某一条“秒杀技巧”，后续若从视频中研究具体方法，将单独记录在 `data/research-log.csv` 并用真题验证。

## 4. GitHub Study Coach Skill

公开 `study-coach-skill` 强调：

- 主动回忆优先于只看总结；
- 先诊断，再教学；
- 对“半懂/不会”再次讲解；
- 间隔复习与错题复盘。

本仓库吸收为：

`框架恢复 → 闭卷回忆 → 真题验证 → 错误模式 → 间隔复测`

而不是单纯堆积笔记。

## 5. 采用标准

网络方法要进入个人正式方法论，至少满足：

1. 逻辑/数学上成立；
2. 能明确适用条件；
3. 近年真题验证有效；
4. 对用户本人确实提速或提准；
5. 不依赖玄学选项规律。
