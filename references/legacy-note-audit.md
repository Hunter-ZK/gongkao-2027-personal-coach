# 四年前行测旧笔记审计记录

> 目的：旧笔记是本轮恢复的重要起点，但不是不可修改的“标准答案”。本文件记录在迁移到新体系时发现的明显错误、过时风险和使用规则。

## 1. 已确认需要修正的逻辑记号

### 1.1 充分条件的逆否命题

旧笔记中出现：

```text
A → B
逆否：¬B → A
```

这是错误的。

正确为：

```text
A → B
逆否：¬B → ¬A
```

理由：`A→B` 与 `¬B→¬A` 等价；“否定后件即可否定前件”。

### 1.2 “且 / 或”标志词混置

旧翻译推理笔记有一处标题与标志词出现互换。新体系统一为：

```text
A且B：两者同时成立
常见词：且、和、既……又……、不仅……而且……

A或B：至少一个成立
常见词：或、或者、至少一个
```

德摩根律：

```text
¬(A且B) = ¬A 或 ¬B
¬(A或B) = ¬A 且 ¬B
```

## 2. 结构性问题

### 2.1 资料分析笔记标题复制错误

旧资料分析文件内部存在“判断推理”等复制遗留标题，不影响核心公式，但迁移时按资料分析重新整理。

### 2.2 技巧缺少适用条件

旧笔记中部分速算/口诀只记录“怎么做”，没有记录：

- 选项差距要求；
- 误差方向；
- 什么时候不能用；
- 与常规方法相比是否真的提速。

新笔记对技巧统一增加“适用条件 / 失效条件”，避免把近似法当精确法。

### 2.3 广东当前题型覆盖缺口

旧笔记没有独立的：

- 政治理论体系；
- 广东科学推理体系。

因此这两部分不能只靠旧笔记恢复，需要按当前大纲新建。

## 3. 迁移规则

旧笔记内容分四档处理：

- **保留**：逻辑/数学上正确，仍有考场价值；
- **改写**：核心思路正确，但表达冗长或缺适用条件；
- **修正**：存在明确逻辑、公式或标记错误；
- **淘汰**：依赖玄学选项规律、无稳定真题证据或已不适应当前题型。

## 4. 后续审计机制

以后发现旧笔记与新题冲突时，不直接覆盖历史文件，而是：

1. 在本审计文件记录问题；
2. 在 `notes/xingce/` 新笔记中使用修正版；
3. 在 `data/methods.csv` 标记该方法的验证状态；
4. 经近年真题验证后再进入 `progress/personal-methodology.md`。
