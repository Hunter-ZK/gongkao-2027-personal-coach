## 3. 路线修订：Phase 0A-R 系统快速恢复

用户明确偏好：在继续大量诊断/定点补漏前，先把四年前学过的行测方法较系统地恢复一遍。

因此当前路线改为：

```text
首个冷启动样本
→ 行测完整题型地图恢复
→ 各模块核心公式/方法/速算恢复
→ 闭卷主动回忆
→ 少量分模块真题验证
→ 多模块恢复测
→ 广东90分钟完整基线
```

这不是回到“完整基础班从头听一遍”。目标是用2–4天重新加载完整框架，再用真题识别真正的薄弱环节。

### 内容来源原则

新笔记不是简单复制旧笔记，也不是拼接名师讲义，而是：

1. 以用户旧笔记的题型架构为恢复入口；
2. 参考公开网络课程/复盘中成熟的实战框架；
3. 用标准数学、逻辑、语言规则重新校验；
4. 对老师技巧记录适用条件，不把“秒杀法”直接视为普遍规律；
5. 经近年真题验证后，才进入 `progress/personal-methodology.md`。

### 已发现并修正的旧笔记问题

至少两处：

- `A→B` 的逆否应为 `¬B→¬A`；
- 旧翻译笔记有一处“且/或”关键词互换。

详见 `references/legacy-note-audit.md`。
