# 当前备考状态

> 初始化日期：2026-09-13  
> 当前阶段：Phase 0A 冷启动诊断 + 快速唤醒  
> 第一目标：2027 广东省考——省直 / 深圳市直综合管理职位  
> 第二目标：2027 国考——中央机关及其省级直属机构综合管理类（传统“副省级”目标）

## 1. 官方规则状态

截至 2026-09-13，尚未检索到 2027 国考或 2027 广东省考正式公告 / 大纲，因此暂以 2026 最新规则作为训练基线，2027 正式规则发布后立即覆盖。

### 广东省考临时训练基线
- 行政职业能力测验：90 分钟，满分 100。
- 申论：150 分钟，满分 100。
- 目标职位方向：省级职位 / 市级综合管理类职位，对应 2026《申论一》。
- 行测模块：政治理论、常识应用、言语理解与表达、数量关系、判断推理、资料分析。
- 广东与国考分别建模，不共享固定做题顺序和模块时间。

### 国考临时训练基线
- 行政职业能力测验：120 分钟，满分 100。
- 申论：180 分钟，满分 100。
- 目标卷型：中央机关及其省级直属机构综合管理类。
- 行测模块包含政治理论、常识判断、言语理解与表达、数量关系、判断推理、资料分析。

## 2. 已知能力先验

仅作为历史先验，不作为当前能力结论：
- 四年未系统复习，当前真实水平未知。
- 历史强弱自评：资料分析 > 判断推理 > 言语理解 > 数量关系 > 常识。
- 申论为历史明显短板，本轮需要重建。
- 用户不希望重新完整听基础系统课，优先使用旧笔记和真题完成快速恢复。

## 3. Phase 0 执行修订

原始规划中的“第一天直接完整广东行测卷”已调整。

原因：四年停训后，冷整卷能测当前裸考状态，但会把“方法暂时提取不出来”“模块节奏尚未恢复”与真正的知识缺口混在一起，诊断成本较高。

因此 Phase 0 拆为：

### Phase 0A：低成本冷启动诊断 + 快速唤醒
- 多模块近年真题小样本；
- 不预习直接作答；
- 根据暴露问题只查看对应旧笔记；
- 换新题复测，观察恢复幅度。

### Phase 0B：恢复后的整卷基线
- 广东行测 90 分钟完整卷；
- 国考目标卷型行测 120 分钟完整卷；
- 广东《申论一》完整或核心诊断。

这样同时保留“起点信息”和“真正可用于制定训练计划的应试基线”。

## 4. 当前需要测量

- 方法提取率：看到题后能否快速识别题型与方法；
- 冷启动正确率与用时；
- 经过一次旧笔记唤醒后的正确率 / 用时变化；
- 传统模块中 A/B/C 三类问题占比；
- 政治理论等新模块的独立基础；
- 申论找点、归类、规范表达和限时完成能力；
- 工作日 / 周末真实可持续学习产能。

## 5. 当前阶段禁止提前确定

在诊断和整卷基线完成前，不确定：
- 永久答题顺序；
- 固定模块时间；
- 长期专项题量；
- 大规模课程清单；
- 2–3 周正式恢复计划。

课程只能由真实训练数据触发。
