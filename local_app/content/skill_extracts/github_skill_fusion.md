# GitHub 公考 Skill 融合摘录（可检索二级证据）

> 用途：给本地 AI 教练和知识体系提供“二级证据层”。本文件不是任何老师本人官方讲义，也不把 GitHub 整理者的归纳冒充老师原话。正式知识节点与用户真实训练证据优先级更高。

## 1. KeWang0622 / kaogong-skill

来源：`KeWang0622/kaogong-skill`，`skills/kaogong/SKILL.md`。

### 可采用的产品/教学规则

- 先识别用户当前模式：行测单题、申论、计划、时政/规则、报考等，再加载对应知识，而不是一次把全部资料塞给模型。
- 单题教学要做到：题型识别 → 正确答案 → 解题思路 → 易错点 → 同类题方法总结。对本工作台进一步收敛为：识别信号 → 主方法 → 最短安全路径 → 边界/止损 → 下次规则。
- 计划必须可执行，要有时间、题量/材料、阶段检测点；不能只写“加强某模块”。
- 涉及公告、评分、题量、职位条件等时效事实时，区分官方、权威媒体、行业整理；不确定就外部核验。
- 模拟题不能冒充真题；训练评分不能冒充官方阅卷分。

### 不直接照搬

- “默认 AI 出题训练”不作为本用户主流程。本平台真题/真实训练优先，仅在用户明确要求时生成模拟题。
- 通用三阶段计划仅作候选，实际阶段由个人证据和晋级条件驱动。

## 2. tyf152119-web / wangyou-honglingjin-perspective

来源：`tyf152119-web/wangyou-honglingjin-perspective`，公开材料研究型 Skill。

### 五个可迁移心智模型

1. **候选差距决定够用精度**：误差不会跨越候选差距就估；可能改变排序再升级精度。政策资格等高风险事实不适用粗估。
2. **卡住必须有降级路径**：先换入口/借选项，再回基础法；基础法仍超预算则跳，不在同一技巧上无限加时。
3. **不确定性分层**：已知、结构推断、模糊印象、纯蒙分开记录；只展开会改变行动的不确定性。
4. **复盘过程故障**：调度、读取、知识、方法、执行、恢复六类故障；复盘只保留 1–2 条下一次可验证修复规则。
5. **按个人约束设计策略**：标准打法只是候选，要结合稳定正确率、速度、考试剩余时间和真实产能。

### 九条决策启发式（压缩版）

- 先硬筛，再优化。
- 先找最便宜的强线索。
- 候选差距决定计算精度。
- 技巧连续卡住就降级。
- 给不确定性贴标签。
- 低退出成本时保留选择权。
- 高耗时低突破率先跳。
- 考前不随意推翻已经验证的体系。
- 复盘必须产出可执行修复，而不是写情绪感想。

### 在工作台中的具体用法

- AI 错题解析必须写“入口、降级、停止条件”。
- 做题看板不只展示正确率，也展示样本量和时间代价。
- 正确但超时、蒙对、反复纠结都不自动判定为“掌握”。

## 3. WangJunqing-coder / huasheng13-skill

来源：`WangJunqing-coder/huasheng13-skill`，GitHub 二次整理 Skill。

### 可纳入的方法骨架

- 资料分析：ABRX 对象/时期/关系定位；截位直除；415 份数；假设分配；增长率/增长量/比重/平均数/倍数。
- 数量关系：特殊值、比例、方程、代入排除；工程/行程/利润/排列组合/容斥/最值/几何等母题。
- 言语理解：语境、中心句、关联关系、选项替换验证；逻辑填空、中心理解、排序/衔接等。
- 判断推理：图形规律、定义要素、类比关系层级、翻译推理、加强削弱。
- 套题复盘：模块正确率、用时分布、薄弱题型、错误归因、下一轮专项。

### 风险边界

- 固定答题顺序、固定模块题量、固定单题时间属于经验性策略或特定考试版本，不在本平台写成普遍定理。
- “某技巧秒杀”必须能说明原理、适用条件和失败后的基础法。
- GitHub Skill 对老师公开体系的总结属于二次整理，人物归属需要一手证据才能确认。

## 4. Suny0u17g / xiaop-data-analysis-skill

来源：`Suny0u17g/xiaop-data-analysis-skill`。

### 资料分析六步法

1. **翻译题干**：时期、对象、问法、单位、限定词先确认。
2. **扫选项**：先看正负、量级、选项间距、简单标杆、是否适合代回。
3. **先定性/定范围**：比重升降、平均数升降、混合值区间、增长量方向等先排选项。
4. **选最低成本算法**：直接读数/排除 > 简单分数与补偿 > 差分/线段 > 假设代入 > 精算。
5. **设误差护栏**：明确近似方向和可能误差；卡两个选项时只精修关键一步，不全题重算。
6. **复核坑位**：基期/现期、单位、百分点、增长量/率、倍数表述、图表口径。

### 强制决策规则

- 先看问法和选项，再动数据。
- 先定性，后计算。
- 能用选项就不要脱离选项长算。
- 只要唯一选项已经稳定确定，就停止继续计算。
- 选项贴近、估算方向不明、判断题卡边界时再升级精度。
- 复盘只问三件事：最早哪里可排除、哪个计算本可不做、选项变近时该补哪一步。

## 5. heihei999 / huasheng-mcp（结构参考，不直接当方法事实）

来源：`heihei999/huasheng-mcp`。

该项目把行测知识做成大量“方法卡 + 题型路由 + 方法搜索 + 模块 scaffold”，其价值主要在**知识产品结构**：

- 先题型分类，再检索相关方法卡；
- 方法卡可独立被 AI 调用，而不是整本讲义一次加载；
- 图形、定义、类比、逻辑、数量、言语分别提供分析 scaffold；
- 方法本身保留来源引用。

本工作台采用这种“节点/方法卡可检索”的结构，但不因其卡片数量或测试声明而自动认为方法正确；具体方法仍需回到本地正式知识节点、用户资料与真实题目验证。

## 6. AI 教练融合纪律

当以上来源出现冲突时：

1. 用户提供的一手材料 / 官方规则 / 真实题面证据优先；
2. 本地正式知识节点与已验证结构化方法次之；
3. 多个独立 GitHub 整理一致时提高候选可信度，但仍属于二级证据；
4. 单一 Skill 的口诀、老师归属、固定时限，不自动写进正式知识；
5. AI 输出必须区分“本平台采用”“GitHub Skill 整理”“可确认一手来源”三种表述。
