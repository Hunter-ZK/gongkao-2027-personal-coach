# 2027 公考个人备考系统 PRD v1.0

## 1. 产品定位

面向有较强行测基础、需要系统恢复、训练验证和长期数据管理的个人备考系统。产品形态为：**数据驾驶舱 + 学习系统 + 题型知识体系 + 错题复训 + PDF训练导入 + 学习时间管理**。

第一目标：2027 广东省考省直 / 深圳市直；第二目标：2027 国考。国考承担更高强度的行测实力校准，广东省考后期根据行测稳定程度提高申论投入。

## 2. 核心用户场景

1. 早上打开首页查看整体规划、本周学习进度、模块正确率和当前阶段。
2. 按系统安排学习某一行测专题，通过目录逐页复习主方法、速解、边界、名师综合。
3. 点击学习计时，记录真实有效学习时间，并区分深度/专注/碎片时间。
4. 在粉笔等平台完成训练后，把训练记录 PDF 上传到系统。
5. 系统在本地解析 PDF，生成训练记录、逐题记录和错题记录；低置信结果要求人工复核。
6. 在错题复训页进入类似刷题 App 的答题界面，重新选择选项、计时、提交并记录复训结果。
7. AI 后续根据训练结果继续修改 GitHub 中的知识、计划和数据。

## 3. 信息架构

### 3.1 总览
- 考试节点 / 倒计时（公告前显示待公告）
- 本周有效学习目标和真实完成量
- 六模块正确率、样本量、掌握状态
- 今日任务
- 当前阶段与下一阶段门槛

### 3.2 学习计时
- 开始 / 暂停 / 继续 / 结束
- 模块、活动类型、具体任务
- 单次记录落入 SQLite
- 深度学习：>=30min
- 专注学习：15–29min
- 碎片学习：<15min
- 每日汇总：总有效、深度、专注、碎片、次数、深度占比

### 3.3 行测体系
- 六大专题：资料分析、判断推理、言语理解、数量关系、政治理论与常识、广东科学推理
- **每个专题至少 50 个独立学习页**，当前种子目录为 6×50=300 页
- 每页统一结构：题型定义、识别信号、主方法、标准步骤、速解、边界、易错、名师综合、闭卷复盘
- 后续继续扩充经典题、个人错题、个人掌握等级

### 3.4 错题复训
- 左侧错题列表
- 中间题目区：题干、A-D 选项、当前计时、提交
- 右侧答题卡
- 提交后显示正确/错误、正确答案、解析
- 记录复训答案、耗时、是否正确

### 3.5 PDF 导入
- 上传 PDF
- pypdf 提取文字层
- 规则切题
- 自动识别 A-D 选项、正确答案、用户答案、模块
- 保存原始 PDF 到本机 data/uploads
- 写入 training/questions SQLite 表
- 自动进入训练记录；用户答案与正确答案不一致时进入错题本
- 每题保存 import_conf；置信度 <0.7 标记“需人工复核”
- 不做 OCR 作为默认路径，避免错误识别；扫描 PDF 后续可扩展 OCR 适配器

### 3.6 训练记录
- 训练来源、PDF 文件、题量、正确数、正确率、导入时间
- 后续：模块拆分、用时、真题/随机题分层统计

### 3.7 备考规划
- 两周系统恢复
- 分模块计时
- 广东90分钟整卷
- 稳定弱项专项
- 国考120分钟整卷
- 广东行测稳定后提高申论投入

## 4. 技术方案

### 4.1 本地优先
- Python 3.10+
- Flask
- SQLite（Python 标准库）
- pypdf
- 原生 HTML/CSS/JavaScript
- 不需要 Node.js、数据库服务、Docker 或前端构建工具

### 4.2 启动
Windows：`start.bat`

macOS/Linux：`bash start.sh`

脚本自动：创建 `.venv` → 安装 requirements → 启动 `127.0.0.1:8765` → 自动打开浏览器。

### 4.3 本地数据
- `local_app/data/study.db`
- `local_app/data/uploads/`

## 5. 数据模型

### training
训练批次：source、filename、created_at、total、correct、duration_sec、parser_conf。

### questions
逐题：training_id、seq、module、subtype、stem、options、user_answer、correct_answer、explanation、is_correct、raw_text、import_conf。

### review_log
错题复训：question_id、answer、is_correct、duration_sec、created_at。

### study_session
学习时间：subject、activity、task、start_at、end_at、duration_sec、category。

## 6. PDF 解析原则

PDF 解析是“导入辅助器”，不是无条件相信的黑盒。

1. 有文字层的粉笔/训练 PDF 优先自动解析。
2. 识别选项、用户答案、正确答案越完整，置信度越高。
3. 低置信题保存但标记复核，不直接当高可信训练数据。
4. 原始题块保留 raw_text，便于后续修正解析器。
5. 后续根据用户反复上传的实际 PDF 样式，为粉笔格式增加专用 parser adapter，提高准确率。

## 7. UI 原则

- 桌面端优先，信息密度高但分层清楚。
- 首屏回答：当前阶段、学习进度、能力状态、下一步。
- 学习笔记是目录式阅读器，不是长文堆砌。
- 错题复训按刷题产品交互设计：题目主体最大、选项可点击、答题卡辅助导航。
- 后台技术信息不进入首页。
