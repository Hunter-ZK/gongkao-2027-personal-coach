# 行测内容重建审计说明

> 目的：避免再次出现“有300个页面，但页面只是重复模板”的假深度。

## 一、重建原则

行测体系不再以“页数”作为完成标准。**50页/专题只是目录下限，真正验收标准是每页是否有可学习、可执行、可验证的独立内容。**

内容按以下优先级进入系统：

1. **用户原始旧笔记**：保留原有术语、分类、公式、口诀、易错点和做题思路；
2. **高认可公开名师体系**：重点吸收花生十三在资料/数量上的系统方法；
3. **高水平考生公开复盘**：重点吸收网友红领巾关于资料、言语、提速、模考定位等经验；
4. **整卷实战复盘**：陈怀安主要用于节奏、取舍、短路径和整卷执行；
5. **数学 / 形式逻辑 / 真题校验**：任何口诀、秒杀法、固定顺序都必须过这一层门禁。

## 二、已修正的旧问题

此前存在两个明确问题：

- 把“50个目录节点”写得像“50页教材已经完成”；
- 大量页面复用同一组通用话术，只换题型标题。

这两个问题已经取消。

当前体系拆成：

```text
knowledge_catalog.py        # 6模块×50节点目录
content_pack_data.py        # 资料50页逐页内容
content_pack_judgment.py    # 判断50页逐页内容
content_pack_verbal.py      # 言语50页逐页内容
content_pack_quantity.py    # 数量50页逐页内容
content_pack_politics.py    # 政治常识50页逐页内容
content_pack_science.py     # 广东科学推理50页逐页内容
knowledge_fullpack.py       # 300节点内容聚合
knowledge_source_core.py    # 用户旧笔记中重新核对出的核心内容
knowledge_curated_extra.py  # 高频节点深度精编
knowledge_examples.py       # 经典模型与训练型例子
knowledge_enriched.py       # 最终内容合并
```

因此现在**300个节点都至少有与该题型独立对应的核心结论、解题步骤和易错点**，不再通过统一模板凑页数。

## 三、旧笔记的真实接入状态

不再声称“9份旧笔记已经完整逐文件镜像到 local_app”。

当前可靠来源有两层：

- 仓库 `references/legacy_notes/` 中已经存在的旧笔记文件；
- 从用户最初上传的完整 Skill / 旧笔记中重新核对出的高价值内容，已写入 `knowledge_source_core.py`。

已经重点接入：

### 资料分析

- 阅读定位、主体/时间/单位；
- 尾数、高位叠加、错位相加、削峰填谷；
- 基准值、分段减法；
- 小分互换、拆分；
- 截位直除；
- 份数法、假设分配、反向分配；
- 分数比较、误差修正；
- ABRX；
- 增长量/增长率/基期/现期；
- 间隔增长、年均增长、混合增长；
- 比重、平均、倍数；
- 各类口径陷阱。

### 判断推理

- 图推位置/样式/属性/数量/空间；
- 对称二级特征；
- 奇点与笔画；
- 六面体相对面/相邻边/公共点；
- 类比一级和二级辨析；
- 定义硬要件；
- 充分必要、逆否、真假；
- 分析推理；
- 加强、前提、因果/实验/一般质疑。

### 言语理解

- 总分、分总、总分总、并列；
- 背景、解释、论证、对策；
- 转折、因果、必要、递进；
- 细节、标题、词句、态度；
- 排序的首句/捆绑/顺序/尾句；
- 填句与接语；
- 逻辑填空的逻辑呼应、解释关系、词义/程度/感情色彩/语法辨析。

### 数量关系

- “第一反应能识别技巧就用，否则不要耗时找技巧”；
- 代入排除；
- 整除、余数、奇偶；
- 方程/不定方程；
- 工程、行程、利润、最值；
- 排列组合、概率；
- 容斥、浓度；
- 特殊情景和几何。

## 四、外部方法进入系统的门槛

### 直接采用

满足至少一项：

- 数学或形式逻辑可直接证明；
- 与用户旧笔记高度一致，并被多个成熟公开体系反复使用；
- 在真题中有明确、可重复的适用条件。

### 限制采用

- 截位、份数、假设分配、代入等速解：必须写适用条件和失效条件；
- 固定模块顺序、固定限时：只做候选，等待个人整卷数据；
- 陈怀安式第一视角短路径：用于整卷节奏与取舍，不替代基础原理。

### 不直接采用

- 答案分布蒙题；
- “转折后必重点”“问题后必选对策”等绝对口诀；
- 加强削弱跨题型万能力度排序；
- 不说明条件的“秒杀法”；
- 仅凭老师/机构知名度采纳。

## 五、当前真实完成度

### 已完成

1. **6个模块 × 50个独立节点 = 300个目录节点。**
2. **300个节点全部有题型对应的独立内容包**，至少包括：
   - 本页核心；
   - 标准解题步骤；
   - 高频易错点；
   - 公式/关系（适用时）；
   - 考场记忆句（适用时）。
3. 高频核心节点进一步做了深度精编：
   - 识别信号；
   - 推荐主方法；
   - 速解与短路径；
   - 边界/失效条件；
   - 经典模型；
   - 训练型例子（明确标注非真题）。
4. 旧笔记已核对出的核心内容直接进入学习页，不再只显示AI摘要。
5. 学习页当前顺序为：

```text
核心结论
→ 你的原笔记精华（有来源时）
→ 核心公式/关系
→ 经典模型
→ 识别信号
→ 推荐主方法
→ 速解与短路径
→ 边界/易错
→ 训练型例子
→ 名师与实战方法综合
→ 闭卷复盘
```

### 仍需继续提升

**300个节点已经摆脱统一模板，但还不能宣称300页都具有同等“教材章节级”深度。**

当前高频核心题型明显更深；政治常识、科学推理以及部分长尾节点主要完成了稳定框架和解题规则。后续继续按：

> 用户当前学习顺序 → 高频真题 → 实际错题 → 整卷暴露问题

逐页提高内容密度。

系统不再通过继续新增目录来制造“丰富感”，后续只做**内容深度、典型题、个人错题和验证数据**。
