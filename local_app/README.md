# 本地工作台 V2

在仓库根目录进入 `local_app` 后启动：

- Windows：双击或运行 `start.bat`
- macOS / Linux：运行 `./start.sh`

工作台使用本机 SQLite 保存个人学习、训练、题库、错题、复训和计时数据。公开代码仓库不保存本地数据库、题目图片、API Key 或个人运行数据。

## 当前信息架构

主导航按三组组织：

- **日常流程**：工作台概览、今日任务推进、专注记录、周度攻坚日程；
- **训练与复盘**：训练记录与题库、错题本与缺陷库、错题智能复训、智能练习导入；
- **知识与方法**：行测考点知识库、申论规范与语料、考场方法库、AI 专属方法教练、能力趋势；
- 设置与当前阶段状态放在侧栏底部。

## 视觉基线

`Civil_gemini2` 是当前正式视觉/交互母版，而不是旧版“少卡片 + 长文阅读”方案：

- 256px 左侧导航；
- 石色 / 白色中性底色；
- 大量信息卡、指标卡、状态标签、Chip、分组表格和可展开区域；
- 训练/题库、错题、复训继续使用已迁移的 Gemini 精确视图；
- 行测知识体系采用三层渐进阅读，默认优先卡片与词库 Chip，不把长篇讲义一次铺满。

## 行测知识体系

每个节点提供：

1. **30 秒快速恢复**：看到什么、第一动作、止损边界、个人真实证据；
2. **标准学习**：定义、原理、识别信号词库、步骤、考场指令、例题、陷阱与相邻方法比较；
3. **深度理解**：完整扩展讲义、来源证据、历史笔记和更多个人训练数据。

所有 V2 方法通过正式 `method_to_node` 映射进入节点，不用关键词临时猜测归属。

## 固定 PDF 一键导入

针对粉笔“快速智能练习”固定版式：

- 自动抽取题目、选项、正确答案、用户答案、题目图片和共享资料；
- 可信版式自动核验并直接写入训练、题库和作答记录；
- 只有异常题进入人工校对；
- 错题自动进入错题本与复训队列；
- 如已配置 AI，后端自动把新增错题提交给本地 Skill / V2 方法体系进行解析。

## 公司 / 家里双设备同步

工作台顶部和设置页提供：

- **提交本机进度**
- **拉取云端进度**

数据交换使用私有 `Hunter-ZK/Civil_gemini2` 仓库的 `gongkao-personal-data` 分支。工作台在 `data/sync-repo/` 维护本机私有同步缓存；拉取前自动备份 SQLite，并对本机/云端同时更新进行冲突保护。

首次在一台新设备同步时，如果 Git 尚未登录 GitHub，需要完成一次能够访问该私有仓库的身份认证。
