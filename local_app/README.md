# 2027 公考个人备考工作台

本地单用户应用。运行数据库为 SQLite；跨会话长期资料以仓库中的结构化导出/历史资产为事实源。V1 不保存 GitHub token，也不自动推送远端。

## 启动
- macOS/Linux: `bash start.sh`
- Windows: 双击或命令行执行 `start.bat`

首次运行自动创建 `.venv`、安装依赖、初始化 `data/study.db`，随后打开 `http://127.0.0.1:8000`。

## 已知边界
考试日期、模块题量与逐题权重中尚未由官方公告确认的值均按估算存储并在界面标识。粉笔 PDF 的低置信解析必须人工确认才进入统计。其他粉笔导出类型必须先提供真实 fixture，再增加专用解析器。
