# 本地工作台

在仓库根目录进入 `local_app` 后启动：

- Windows：双击或运行 `start.bat`
- macOS / Linux：运行 `./start.sh`

工作台默认使用本机 SQLite 保存个人学习、训练、题库、错题、复训和计时数据。GitHub 仓库只保存代码、结构化内容和可版本管理的配置，不提交本地数据库、API Key 或个人运行数据。

## 当前信息架构

主导航固定为 11 项：总览、今日任务、学习计时、训练记录、错题本、错题复训、导入、行测体系、申论、备考规划、能力趋势。方法与结论、设置放在侧栏底部。行测方法不再作为与知识节点竞争的独立入口，而是在行测节点右栏按上下文调用。

## 视觉基线

当前视觉系统以 `03-UI设计规范.md` / `08-改进PRD-视觉与内容返工.md` 为准：224px 浅色侧栏、印刷靛主色、4px 主面板圆角、年鉴式表格、试卷式长文阅读，不使用装饰性渐变和面板投影。
