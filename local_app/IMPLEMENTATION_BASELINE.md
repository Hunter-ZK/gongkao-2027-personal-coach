# Workbench V1 冻结实施基线

本文件记录 2026-09-13 重建开始前已确认的关键决策。实现与测试出现冲突时，以本文件和本次重建规格为准，不再回退到旧版工作台的隐含假设。

- 国考按副省级规划；135题仅为当前历史/规划基线，2027 官方公告发布后校准。
- 国考 70/70 是目标展示，不作为阶段硬门槛。
- 国考暂定 2026-11-29、广东暂定 2026-12-13，均为非官方预测日期。
- 模块/题目分值用于规划时必须标识为估算，不冒充官方逐题评分。
- 广东多选题精确计分规则保持 unknown，等待官方依据。
- SQLite 是本机运行库；可版本化 JSON/CSV 导出用于 GitHub 长期事实源。V1 不内置 GitHub Token 或自动 push。
- 历史数据只在可靠映射时迁移；不补造未知字段。
- 原始旧笔记目前只确认 3 份；其余 6 类明确标记缺失，不用二手整理稿冒充原始笔记。
- 正式内容节点为 30 个行测 + 5 个申论，共 35 个；当前首批建设 12 个行测核心节点。
- 内容 20 段模板以内容生产规范为准：第18段为名师/方法综合，第19段为用户历史笔记对照。
- 无法合法复现的真题不伪称真题；使用时明确标注“同型改编题”。
- mistake.cause_primary 在待诊断状态允许为空。
- PDF 解析结果即便高置信，也必须人工确认后才 verified=1 并进入统计。
- 整组用时均摊只作估算；节点速度门槛只采用可靠计时样本。
- P1 首轮覆盖按 12 个核心节点至少 11 个完成，并且主模块存在有效样本判定。
- V1 计时恢复仅保证同设备刷新/浏览器崩溃/重新打开，不承诺跨设备同步。
- PDF 导出采用打印友好 HTML + 浏览器“打印/另存为 PDF”，不增加重型 PDF 引擎。
- V1 不做本地截图 OCR；截图识别可由外部 ChatGPT 流程处理。
- 粉笔“快速智能练习”按真实 fixture 适配；其他导出类型必须拿到真实样本后再开发，不猜正则。
- Windows/macOS CI 只覆盖安装、启动和接口；真实设备视觉/终端验收未执行前不得标记通过。
