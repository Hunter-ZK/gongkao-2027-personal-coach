# 2027 公考个人备考工作台

> **当前前端入口：[`docs/index.html`](docs/index.html) → 自动进入 V3**  
> **V3 源码：[`docs/v3/`](docs/v3/)**

这是 2027 广东省考 + 国考的长期个人备考系统，定位为：

**数据驾驶舱 + 学习系统 + 行测知识体系 + 错题复训 + 训练记录 + 学习计时 + 阶段规划。**

## 当前目标

1. 第一目标：广东省考——省直 / 深圳市直综合管理；
2. 第二目标：国考——作为高强度行测实力校准节点；
3. 当前阶段：两周行测系统恢复，随后进入分模块计时与整卷。

## V3 前端

`docs/v3/` 已经是真正可运行的静态前端，不再只是 Markdown 蓝图：

- `index.html`：主界面；
- `styles.css`：桌面端优先 UI；
- `data.js`：训练、错题、计划、知识体系数据；
- `app.js`：导航、知识检索、错题详情、学习计时与统计逻辑；
- `PRODUCT_BLUEPRINT.md`：产品基线；
- `TRAINING_ROADMAP.md`：训练路线；
- `KNOWLEDGE_ARCHITECTURE.md`：完整知识体系基线。

### 当前可用功能

- 学习总览：本周路线、模块状态、今日任务、待复训错题；
- 学习计时器：开始 / 暂停 / 继续 / 结束并记录；
- 时间分类：深度学习（≥30 分钟）、专注学习（15–29 分钟）、碎片学习（<15 分钟）；
- 每日 / 近7天统计：总有效时间、深度时间、碎片时间、次数、深度占比；
- 学习明细表：模块、类型、具体任务、开始/结束、时长、分类；
- 浏览器本地持久化：刷新后进行中的计时可恢复，历史记录保留；
- CSV 导出与“复制今日汇总”；
- 行测体系：按模块→一级题型→二级模型→识别信号→主方法→速解→边界→易错→名师综合组织；
- 错题复训：展示原题、选项、你的答案、正确答案、错因、技巧和复训要求；
- 备考规划：两周恢复、分模块计时、广东整卷、专项强化、国考整卷、申论提权；
- 训练记录：当前两组 30 题数据已接入。

## 学习时间判定标准

为先测量真实可用学习产能，V3 暂定：

- **深度学习**：单次有效学习 ≥30 分钟；
- **专注学习**：单次 15–29 分钟；
- **碎片学习**：单次 <15 分钟。

先连续记录 7–14 天，再根据工作日/周末真实数据修正每周 24–30 小时的建议投入，不提前用理论空闲时间代替真实产能。

## 使用方式

1. 打开 V3 工作台，按今日任务学习；
2. 学习时使用计时器；
3. 粉笔 / 真题训练后把结果上传给 AI；
4. AI 负责核验、复盘、更新训练数据、错题、知识状态和下一步计划；
5. 一天结束可在计时器复制“今日汇总”发给 AI，或直接说“收工”。
