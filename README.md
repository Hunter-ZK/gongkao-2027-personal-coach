# 2027 公考个人备考工作台

这是面向 **2027 广东省考（省直 / 深圳市直）+ 国考副省级** 的长期个人备考系统。

> **唯一当前产品入口：[`local_app/`](local_app/)**  
> 旧 `docs/v3` 静态前端叙述已废弃，不再作为实现或产品基线。

## 产品定位

不是静态资料库，也不是单纯 Dashboard，而是一套个人公考学习操作系统：

**计划 → 学习 → 真实训练 → PDF 自动采集 → 题库 / 作答 → 错题诊断 → AI + Skill 解析 → 复训 → 知识与能力状态更新 → 下一轮计划。**

## 当前核心能力

- **Civil_gemini2 视觉基线**：卡片化总览、训练/题库、错题、复训与知识学习页面，保留真实后端数据，不使用演示 mock 数据。
- **行测知识体系**：按知识节点组织，采用“30 秒快速恢复 / 标准学习 / 深度理解”三层阅读；识别信号使用词库 Chip 展示，正式方法拆成可展开卡片，长篇讲义和历史笔记默认折叠但完整保留。
- **PDF 一键导入**：针对固定粉笔“快速智能练习”版式进行几何解析，抽取题干、选项、图片、用户答案、正确答案和共享资料；可信固定模板自动核验并入库，只有异常题进入人工校对。
- **题库与作答分离**：同一道题进入题库后可累计多次 `Attempt`，避免重复题目；训练、题目、作答、错题长期关联。
- **AI 错题诊断**：错题入库后自动提交给本地 `gongkao-method-coach` Skill / V2 方法体系驱动的 AI，生成标准解、考场快解及边界、命题陷阱、建议错因和关联知识节点。
- **错题复训**：原题、错误模式和复训调度分离，跟踪修复与复发。
- **学习计时**：全局专注器、深度/专注/碎片学习统计。
- **计划与能力趋势**：周计划、今日任务、真实训练样本和掌握状态联动。
- **公司 / 家里双设备同步**：本机 SQLite 负责运行，私有 Git Checkpoint 负责跨设备接续；提交一次、另一台设备拉取一次即可继续学习。
- **工作场景禅模式**：可隐藏明显的公考/考试词汇与倒计时。

## 数据与隐私

运行时学习数据默认保存在：

- `local_app/data/study.db`
- `local_app/data/images/`

这些内容不会提交到公开的 `gongkao-2027-personal-coach` 仓库。

双设备同步使用私有 `Hunter-ZK/Civil_gemini2` 仓库的独立分支：

- `gongkao-personal-data`

工作台首次同步时会在本机建立私有同步缓存；之后：

1. 公司电脑学习结束后点击 **“提交本机进度”**；
2. 回家后点击 **“拉取云端进度”**；
3. 拉取前自动备份本机 SQLite；
4. 本机与云端同时有新数据时阻止静默覆盖；
5. DeepSeek API Key、`secrets.json`、本机临时文件不进入同步快照。

首次在新设备使用私有同步时，需要该设备的 Git 已登录能够访问 `Hunter-ZK/Civil_gemini2` 的 GitHub 账号。

## 本地启动

进入 `local_app`：

- Windows：运行 `start.bat`
- macOS / Linux：运行 `./start.sh`

Python 依赖会按项目配置安装；正常使用不要求单独启动 Node 前端开发服务。

## 当前目标

1. 第一目标：广东省考——省直 / 深圳市直综合管理；
2. 第二目标：国考副省级；
3. 当前学习主线：快速恢复行测体系 → 分模块真实题验证 → 时间压缩 → 广东整卷 / 国考整卷；
4. 申论持续训练，不等待行测完成后再开始。

## 关键原则

- 国考与广东分开建模；
- 最新官方规则优先；
- 真题优先，不用大量 AI 自编题替代真实训练；
- 错题必须进入后续复训，不做只存不出的电子错题本；
- 老师 / GitHub Skill 内容是候选证据，最终方法必须经过真实题与个人数据验证；
- 正确率与速度同时评价；
- 长期知识与学习事实可追溯，但默认界面优先降低认知负荷。
