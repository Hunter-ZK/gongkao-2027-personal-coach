# 2027 公考个人训练仓库

目标：用 GitHub 作为 2027 国考 + 广东省考的长期同步工作台，承载计划、训练日志、错题模式、个人方法论、申论表达库、研究记录和阶段复盘。

## 目标优先级

1. 广东省考：省直 / 深圳市直综合管理职位；
2. 国考：中央机关及其省级直属机构综合管理类。

## 当前阶段

**Phase 0A：冷启动诊断 + 快速唤醒**（初始化：2026-09-13）。

四年停训后的第一轮先用低成本真题样本区分“会但生疏”和“真正不会”，再进入广东/国考完整限时卷。仓库不预设永久做题顺序、模块时间或课程清单。

## 日常入口

- `workbench/dashboard.md`：当前工作台；
- `plans/daily/`：每日计划与监督；
- `progress/current_state.md`：阶段状态；
- `data/training-log.csv`：训练数据库；
- `data/error-patterns.csv`：错误模式库；
- `data/methods.csv`：方法论状态库；
- `data/research-log.csv`：外部研究库；
- `evidence/`：截图 / 原始证据；
- `progress/personal-methodology.md`：已验证考场方法；
- `progress/shenlun-expression-bank.md`：申论表达库。

## 工作流

`官方规则核验 → 低成本诊断 → 快速唤醒 → 恢复后整卷基线 → 每日计划 → 真实训练 → 截图回传 → 自动入库 → 错误模式 → 方法论更新 → 下一日计划`
