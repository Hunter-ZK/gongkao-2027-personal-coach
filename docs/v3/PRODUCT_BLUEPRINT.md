# V3 产品蓝图｜2027 公考个人备考中枢

> 定位：**数据驾驶舱 × 学习系统 × 训练记录 × 错题复训**  
> 设备：桌面端优先  
> 目标考试：广东省考（第一优先） + 国考（第二优先、作为行测实力检验）  
> 当前阶段：高基础考生的系统恢复期

---

## 1. 产品定位

这个系统不是资料库，也不是普通 Dashboard，而是用户每天会打开的**个人备考中枢**。

核心任务只有四件：

1. 告诉用户：**离目标还有多远**；
2. 告诉用户：**今天具体做什么**；
3. 帮用户：**随时复习体系化知识和个人错题**；
4. 用真实训练数据持续调整：**下一步应该学什么、练什么、是否进入下一阶段**。

---

## 2. 设计参考与采用原则

### 2.1 Dashboard 层
参考 Linear Dashboard 的“关键指标集中展示 + 可下钻”思路：主屏只放真正影响决策的指标，点击指标进入模块详情。

### 2.2 学习进度层
参考 Khan Academy Mastery：每个知识点不只记录“看过/没看过”，而是使用分级掌握状态，并根据练习结果升级或降级。

本系统拟采用：

- `未恢复`
- `已恢复`
- `可独立做题`
- `稳定`
- `考场稳定`

### 2.3 学习计划层
参考 LeetCode Study Plan：计划不是静态日历，而是“进行中计划 + 单元完成 + 下一任务”。

### 2.4 复习层
参考 Quizlet Learn：知识点和错题进入个性化复习队列，系统按“近期错误 / 已学但不稳定 / 长期未复测”排序。

---

## 3. 首页信息架构

首页遵循“先总体，后细节”。

### 第一屏：战略驾驶舱

#### 3.1 考试卡
- 广东省考倒计时：公告未发布时显示“待官方时间确认”；
- 国考倒计时：同上；
- 当前备考周：Week N；
- 当前阶段：系统恢复 / 专项强化 / 整卷训练 / 冲刺。

#### 3.2 本周进度
- 本周计划学习时长；
- 实际完成时长；
- 计划完成率；
- 本周题量；
- 本周复训完成数；
- 本周新增稳定知识点数。

#### 3.3 模块表现
展示：
- 资料分析
- 判断推理
- 言语理解
- 数量关系
- 政治理论/常识
- 广东科学推理

每个模块展示：
- 当前正确率；
- 样本量；
- 平均速度；
- 掌握度；
- 与上周变化；
- 当前风险标签。

#### 3.4 当前短板
只展示 3–5 个真正影响考试的短板，不显示后台型问题。

例如：
- 数量：正确率尚可，但题均耗时偏高；
- 言语：尚未形成当前样本；
- 加强论证：相关性判断出现一次错误，待复测；
- 资料：首组基期/比重错误，第二组已恢复，继续观察。

---

### 第二屏：今日行动

#### 今日学习计划
按“主模块 + 轻量模块”组织。

每个任务展示：
- 任务名称；
- 为什么今天做；
- 预计时间；
- 完成标准；
- 是否需要上传结果。

示例：

**P0｜资料分析系统恢复（80min）**
- 30min：知识树恢复；
- 10min：闭卷回忆；
- 25min：12题真题；
- 15min：错题复盘。

完成标准：
- 回忆题 ≥80%；
- 真题 ≥80%；
- 能说清当前仍不稳定的二级题型。

#### 今日复训
显示 3–8 道到期错题，可直接进入“复训模式”。

## 5. 行测体系页面

### 左栏：知识树

结构：

`模块 → 一级题型 → 二级题型 → 经典模型`

支持：
- 展开/收起；
- 搜索；
- 只看“未稳定”；
- 只看“有错题”；
- 只看“近期复习”。

### 中栏：当前知识点

每个知识点必须包含：

1. **识别信号**
2. **主方法**
3. **步骤**
4. **速解方法**
5. **适用条件**
6. **什么时候不用**
7. **常见错法**
8. **经典模型**
9. **老师/来源扩展**
10. **个人训练数据**
11. **关联错题**
12. **下一次复测时间**

### 右栏：个人状态

- 当前掌握级别；
- 做题次数；
- 正确率；
- 最近5题；
- 最近错误；
- 平均耗时；
- 是否建议专项训练。

---

## 6. 错题本页面

### 列表视图
每条错题必须直接显示：
- 题目摘要；
- 来源；
- 模块/题型；
- 用户答案；
- 正确答案；
- 首次日期；
- 最近复训日期；
- 状态：待复训 / 改善 / 已稳定 / 重复错误。

### 详情页
完整展示：
- 原题；
- 题图；
- 选项；
- 用户答案；
- 正确答案；
- 用户当时用时（有则显示）；
- 错因；
- AI完整解析；
- 最稳解法；
- 最快解法；
- 关联知识点；
- 关联方法卡；
- 相似题型；
- 复训历史。

### 复训模式
点击“重新训练”后：
- 默认隐藏答案与解析；
- 显示原题；
- 用户自行作答；
- 点击“显示答案”；
- 用户把结果发给 AI；
- AI 回写状态。

当前阶段不做浏览器自动判分，保持“记录型系统”。

---

## 7. 备考计划页面

分两个独立视图。

### 7.1 时间规划视图

层级：
`考试节点 → 月 → 周 → 日`

展示：
- 当前周目标；
- 每日计划；
- 完成率；
- 延期任务；
- 调整后的计划。

### 7.2 能力规划视图

层级：
`目标考试 → 模块目标 → 当前状态 → 差距 → 下一训练动作`

示例：

| 模块 | 当前 | 阶段目标 | 差距 | 下一动作 |
|---|---|---|---|---|
| 资料 | 8/10，小样本 | 恢复后稳定高正确率+速度 | 需扩大样本 | 系统恢复+计时真题 |
| 数量 | 4/5但偏慢 | 建立必做题池与止损 | 速度未量化 | 记录识别/建模/计算耗时 |

## 8. 数据分析页面

只保留真正影响备考决策的数据：

- 模块正确率趋势；
- 模块题均耗时趋势；
- 错误类型分布；
- 知识点掌握分布；
- 每周训练量；
- 每周有效学习时间；
- 错题修复率；
- 全真卷成绩趋势；
- 广东卷 vs 国考卷对比。

## 9. UI 方向

### 视觉
- 桌面端优先；
- 高信息密度但不过度拥挤；
- 不做“互联网后台管理系统”风；
- 不大量使用渐变卡片；
- 左侧固定主导航 + 顶部当前上下文 + 中央主区；
- 内容页支持 3 栏结构；
- 大量使用表格、树、趋势图、状态标签、可折叠详情。

### 交互
- 首页指标可点击下钻；
- 错题一键打开详情；
- 知识树点击立即切换内容；
- 支持搜索题型/错题/方法；
- 支持快捷过滤：未稳定 / 有错题 / 近7日训练 / 待复训；
- 计划页支持周切换；
- 所有数据页面都能回到原训练记录。

---

## 10. 技术方案

当前最优：

**前端 SPA + GitHub 结构化 JSON + AI 持续写回**

原因：
- 用户无需自行维护后端；
- 当前训练数据量不大；
- GitHub 已作为长期事实库；
- 前端可以完整实现驾驶舱、知识树、检索、下钻、错题详情和计划展示；
- 后续若需要，可平滑迁移到 SQLite / Supabase / 自建 API。

不在当前阶段增加：
- 登录系统；
- 浏览器自动判题；
- 多用户权限；
- 服务端任务队列。

这些不影响当前核心目标。
