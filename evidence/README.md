# 原始证据区

用于保存或索引训练截图、成绩页、PDF、申论原稿等原始证据。

## 命名

`YYYY-MM-DD-training-NNN-来源-类型.ext`

## 原则

1. 原始证据负责追溯，`records/`负责可检索结构化复盘；
2. 不要求用户为归档重新手抄题目；
3. 当前GitHub连接的文本写入接口不适合直接同步会话中的二进制附件时，先保证标准化记录、题目结果和错误模式完整入库；
4. 后续若原始附件可直接写入仓库，再补齐二进制镜像，不影响训练闭环。
