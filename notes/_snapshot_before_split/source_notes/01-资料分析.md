# 资料分析｜系统快速恢复笔记

> 架构沿用你的旧笔记：**阅读 → 速算 → ABRX → 比重 → 平均 → 倍数 → 特殊增长 → 陷阱**。  
> 网络研究主要参考公开课程框架中反复出现的：速算、ABRX、份数思维、比重/平均/倍数、材料定位等模块；不复制课程讲义原文。

## 0. 一页速览

资料分析做题主线只有四步：

1. **圈主体**：谁；
2. **圈时间**：哪一年/同比/环比/基期；
3. **圈单位**：亿元、万人、万吨、%、百分点；
4. **识别问法**：求量、求率、求差、比大小、判断趋势。

先列关系，再决定是否精算。资料分析最常见的低级错误不是“不会算”，而是**主体错、年份错、单位错、公式对象错**。

# 1. 阅读与定位

## 1.1 文字材料

[旧] 先找段落主题词；结构清楚时按总分关系定位；数据密集时只读题目对应主体，不通读所有数字。

**执行规则**：

- 题目先读，再回材料定位；
- 数字旁边同时确认“主体+时间+单位”；
- “其中”“占”“同比”“累计”“当月”必须圈；
- 表格优先看标题、横纵表头、单位；
- 图形优先看标题、横纵轴、图例、坐标是否截断。

## 1.2 高频陷阱

- “增长量”与“增长率”混；
- “百分点”与“百分比”混；
- “当月”与“累计”混；
- “比上年增长”与“比上年增加多少”混；
- “超过/不足/约为”改变精度要求；
- 现期、基期主体不一致。

# 2. 核心四量：A、B、X、R

[旧][统]

定义：

- `A`：基期量
- `B`：现期量
- `X`：增长量
- `R`：增长率

核心关系：

```text
B = A(1+R)
X = B-A = AR
A = B/(1+R)
X = B×R/(1+R)
R = X/A = X/(B-X)
```

## 2.1 看到什么就想什么

- “今年 B，同比增长 R，去年多少” → `A=B/(1+R)`
- “今年 B，同比增长 R，增加多少” → `X=B×R/(1+R)`
- “今年 B，比去年增加 X，增速多少” → `R=X/(B-X)`
- “增长率为负” → `1+R` 小于 1，基期通常大于现期

## 2.2 份数思维

[旧][研][统]

当增长率接近简单分数时，不必长除。

例如 `R≈1/n`：

```text
A : X : B ≈ n : 1 : n+1
X ≈ B/(n+1)
A ≈ nB/(n+1)
```

常用百分数—分数：

| 百分数 | 分数 |
|---:|---:|
| 50% | 1/2 |
| 33.3% | 1/3 |
| 25% | 1/4 |
| 20% | 1/5 |
| 16.7% | 1/6 |
| 14.3% | 1/7 |
| 12.5% | 1/8 |
| 11.1% | 1/9 |
| 10% | 1/10 |
| 9.09% | 1/11 |
| 8.33% | 1/12 |
| 7.69% | 1/13 |
| 7.14% | 1/14 |
| 6.67% | 1/15 |
| 6.25% | 1/16 |
| 5% | 1/20 |
| 4% | 1/25 |
| 2.5% | 1/40 |

**失效条件**：选项极近、增长率离简单分数较远时，不要硬套份数近似。

# 3. 速算工具箱

公开课程中花生十三的资料体系把“加减乘除速算、ABRX、份数思维”等单独训练；你的旧笔记也有同样结构。这里保留真正能在考场稳定使用的部分。

## 3.1 加减法

- **高位叠加**：从高位开始估，先看选项差距；
- **基准值**：一组相近数字求和/平均，用“基准×个数 + 偏差和”；
- **分段减法**：大数相减时分段处理，避免反复借位；
- **尾数法**：只有在选项尾数明显区分且题目要求精确时使用。

## 3.2 乘法

优先拆成简单比例：

```text
A×12% = A×(10%+2%)
A×37.5% = A×3/8
A×16.7% ≈ A/6
```

若选项差距大，先保留 2–3 位有效数字；不要默认所有乘法都算到个位。

## 3.3 除法

### 截位直除

- 比较大小：通常截 2–3 位有效数字；
- 求精确区间：根据选项差距决定多保留一位；
- 分子分母同时同比例缩放不改变比值；
- 分母接近整百/整千可做等价近似，但要判断误差方向。

### 差距优先

选项差距 10% 时，不值得算到 0.1%；选项差距 1% 时，才需要更细。

## 3.4 分数比较

比较 `a/b` 与 `c/d`：

- 数字小：交叉相乘；
- 两个分数都接近某一基准值：比较偏离；
- 同分子：分母小者大；
- 同分母：分子大者大；
- 分子、分母都更大：不要凭直觉，回到交叉相乘或增长率比较。

# 4. 增长率专题

## 4.1 普通增长率

```text
R=(B-A)/A
```

比较两个增长率时，若基期不同，不能只比增长量。

## 4.2 间隔增长率

[旧][统]

连续两期增长率 `r1、r2`：

```text
R = r1 + r2 + r1×r2
```

若均为正，结果大于简单相加；一正一负时注意乘积项为负。

## 4.3 年均增长率

精确式：

```text
(末期/初期)^(1/n)-1
```

若比较对象的年份跨度相同，可直接比较 `末期/初期`，通常不用开方。

## 4.4 混合增长率

两个部分合成总体：总体增长率位于两个部分增长率之间，并更接近**基期权重更大**的一方。

精确本质：

```text
总体增长率 = (各部分基期量×各自增长率之和) / 总体基期量
```

遇到“整体 + 两部分”题，先用“居中”排除，再决定是否精算。

# 5. 比重专题

## 5.1 现期比重

```text
现期比重 = 部分现期 / 整体现期
```

## 5.2 基期比重

若部分现期为 `a`、增长率 `ra`；整体现期为 `b`、增长率 `rb`：

```text
基期比重 = (a/b) × (1+rb)/(1+ra)
```

### 秒判方向

- `ra > rb` → 部分长得更快 → **现期比重高于基期**；
- `ra < rb` → **现期比重低于基期**。

## 5.3 两期比重变化

题目问“上升/下降几个百分点”：

```text
变化 = 现期比重 - 基期比重
```

方向先用 `ra` 与 `rb` 判断，再计算大小。

可推导：

```text
现期比重-基期比重
= 现期比重 × (ra-rb)/(1+ra)
```

实战中先判断正负、看选项，再决定是否代公式。

### Training-001 对应

Q12 的本质就是两期比重差。以后看到“占比较上年增加/下降多少个百分点”，第一反应必须是：**先算两个比重或用增长率关系判断方向，不拿增长率差直接当百分点差**。

# 6. 平均数专题

## 6.1 现期平均数

```text
平均数 = 总量/份数
```

## 6.2 基期平均数

若总量增长率为 `ra`、份数增长率为 `rb`：

```text
基期平均数 = 现期平均数 × (1+rb)/(1+ra)
```

## 6.3 平均数变化方向

- `ra > rb` → 平均数上升；
- `ra < rb` → 平均数下降。

平均数增长率：

```text
(ra-rb)/(1+rb)
```

# 7. 倍数专题

## 7.1 现期倍数

```text
A是B的几倍 = A/B
A比B多几倍 = A/B - 1
```

“多几倍”和“是几倍”必须区分。

## 7.2 基期倍数

若两对象增长率分别为 `ra、rb`：

```text
基期倍数 = 现期倍数 × (1+rb)/(1+ra)
```

方向判断同平均数/比重，本质都是两个量之比。

---

# 8. 增长量专题

```text
X = B×R/(1+R)
```

## 8.1 比较增长量

不要默认“现期大、增速高”就一定增长量大；但如果一个对象同时满足：

- 现期更大；
- 增长率更大；

通常可直接判断增长量更大，无需计算。

## 8.2 年均增长量

```text
(末期-初期)/年份间隔数
```

注意“2019—2023”有 4 个增长间隔，不是 5。

# 9. 综合分析题

通常最后一题问“以下正确/错误的是”。策略：

1. 先做能秒判的选项；
2. 先看无需复杂计算的选项；
3. 避免按照 A→B→C→D 固定顺序死算；
4. 一旦找到确定答案立即停，不给其他选项做无意义验算。

---

# 10. 资料分析考场规则

1. **先看问题，再定位材料**；
2. **主体、时间、单位三件套必须对齐**；
3. 先判断数量级和方向，再精算；
4. 选项差距决定精度；
5. 能比较不计算，能估算不精算；
6. 公式只背关系，不背孤立字母；
7. 算出一个答案后检查“问的是增长量/增长率/百分点/倍数中的哪一个”。
