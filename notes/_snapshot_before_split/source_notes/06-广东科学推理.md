# 1. 力学

## 1.1 牛顿运动

```text
F合 = ma
```

- 匀速直线运动 → 合力为0；
- 静止 → 合力为0；
- 有加速度 → 合力方向与加速度方向一致。

### 斜面

常见受力：

- 重力；
- 支持力；
- 摩擦力；
- 外力/拉力。

**摩擦力方向**：总是阻碍相对运动或相对运动趋势，不是固定“向后”。

## 1.2 功与功率

```text
W = Fs cosθ
P = W/t
```

同样做功，时间越短，功率越大。

## 1.3 动能与势能

```text
Ek = 1/2 mv²
Ep = mgh
```

忽略阻力时，机械能可守恒；有摩擦时部分机械能转化为内能。

## 1.4 压强

固体：

```text
p = F/S
```

液体：

```text
p = ρgh
```

液体压强与容器形状无直接关系，主要由密度、深度决定。

## 1.5 浮力

阿基米德原理：

```text
F浮 = ρ液 g V排
```

漂浮：

```text
F浮 = G
```

同一物体漂浮在不同液体中，浮力都等于重力，但排开液体体积不同。

# 2. 简单机械

## 2.1 杠杆

平衡条件：

```text
F1·l1 = F2·l2
```

动力臂越长，所需动力越小。

## 2.2 滑轮

- 定滑轮：主要改变力方向，不省力；
- 动滑轮：理想情况下省力，但费距离；
- 滑轮组：看承担重物的绳子段数。

机械省力不等于省功；理想机械满足功守恒。

# 3. 电学

## 3.1 基础关系

```text
U = IR
P = UI = I²R = U²/R
W = Pt
```

## 3.2 串联

- 电流相同；
- 总电压等于各电压之和；
- `R总=R1+R2+...`

## 3.3 并联

- 各支路电压相同；
- 总电流等于各支路电流之和；
- 总电阻小于任一支路电阻。

两个电阻并联：

```text
R总 = R1R2/(R1+R2)
```

## 3.4 电表示数

- 电流表理想状态电阻近似0，串联；
- 电压表理想状态电阻很大，并联。

电路变化题先判断：等效电阻变大/变小 → 总电流如何变 → 各支路如何变。

# 4. 光学

## 4.1 反射

```text
入射角 = 反射角
```

平面镜成像：

- 虚像；
- 正立；
- 等大；
- 像距=物距。

## 4.2 折射

光从一种介质进入另一种介质，传播方向可能改变。

从空气斜射入水/玻璃，一般向法线偏；反向则远离法线。

## 4.3 凸透镜

核心记忆：

- `u>2f`：倒立缩小实像；
- `u=2f`：倒立等大实像；
- `f<u<2f`：倒立放大实像；
- `u<f`：正立放大虚像。

---

# 5. 热学

## 5.1 热量

```text
Q = cmΔT
```

同质量、同温升下，比热容越大吸热越多。

## 5.2 物态变化

- 熔化、汽化、升华：吸热；
- 凝固、液化、凝华：放热。

沸腾与蒸发都属于汽化，但沸腾在特定温度下发生于液体内部和表面。

## 5.3 热传递

- 传导；
- 对流；
- 辐射。

真空中可通过热辐射传热。

---

# 6. 密度与质量

```text
ρ = m/V
```

同种物质正常状态下密度近似固定；质量变小不代表密度一定变小。

混合、空心、排水体积题先画出 `m、V、ρ` 三量关系。

# 7. 化学基础

## 7.1 物理变化 vs 化学变化

判断是否生成新物质。

- 熔化、蒸发、破碎：通常物理变化；
- 燃烧、锈蚀、发酵：化学变化。

## 7.2 酸碱

- pH<7：酸性；
- pH=7：中性；
- pH>7：碱性。

酸碱中和生成盐和水是常见基础模型。

## 7.3 氧化还原日常判断

燃烧、金属锈蚀等常涉及氧化过程，但具体题仍以反应条件为准。

# 8. 生物与生活科学

## 8.1 人体基础

- 呼吸系统：气体交换；
- 循环系统：物质运输；
- 消化系统：消化吸收；
- 神经/内分泌：调节。

## 8.2 遗传与生态

- DNA 是主要遗传物质；
- 生态系统包含生物成分和非生物环境；
- 食物链中的能量逐级传递并损耗。

## 8.3 微生物

病毒没有完整细胞结构，不能独立进行完整生命活动；细菌属于原核生物。

# 9. 图像与实验题

## 9.1 图像

先看：

- 横轴/纵轴分别是什么；
- 单位；
- 正负；
- 斜率表示什么；
- 面积是否有物理意义。

例如 `v-t` 图：

- 斜率代表加速度；
- 图线与时间轴围成的有符号面积代表位移。

## 9.2 实验控制变量

要比较某因素影响：

- 只改变研究因素；
- 其余条件尽量相同；
- 有对照组；
- 重复实验提高可靠性。

# 10. 科学推理考场策略

1. 先做纯定性关系题；
2. 能用守恒/方向/大小比较排除，不必精算；
3. 复杂图先读轴再看图；
4. 记不清专业知识时，优先检查量纲、极端情况和因果方向；
5. 题干给新公式时，把它当数学关系用，不需要事先知道该公式；
6. 遇到明显超出基础知识的题，先跳，不能拖垮广东90分钟节奏。
