# 一、资料分析

## 1. 先定位，再计算：主体 × 时间 × 单位

每道题先确认三件事：

1. **主体**：哪一地区/行业/板块/人群；
2. **时间**：现期、基期、同比、环比、累计、当月；
3. **单位**：亿元、万人、万吨、%、百分点。

很多资料题不是公式不会，而是拿错数据。表格题还要额外确认横纵表头；图表题先看标题、坐标轴和图例。

## 2. 选项差距决定精度

### 核心思想
不是“看到除法就截三位”，而是先问：**选项到底离得有多远？**

- 差距很大：2位有效数足够；
- 差距中等：3位；
- 差距很小：直除或精算；
- 能定性比较：不算；
- 能用上下界排除：不求具体值。

### 误差方向
若分子放大、分母缩小，所得商偏大；反之偏小。近似值一旦落在两个选项之间，就必须提高精度，不能“凭接近”硬选。

## 3. ABRX 不背字母，背关系

设：

- 基期 `A`
- 现期 `B`
- 增长量 `X`
- 增长率 `R`

```text
B=A(1+R)
X=B-A=AR
A=B/(1+R)
X=B×R/(1+R)
R=X/A=X/(B-X)
```

### 快速自检

- 正增长：基期 < 现期；
- 负增长：基期 > 现期；
- 增长量绝对值不可能大于现期很多倍；
- 增长率最终是无量纲比例。

## 4. 份数法：把增长率变成整数比例

当 `R≈1/n`：

```text
基期 : 增长量 : 现期 ≈ n : 1 : n+1
```

例如增长约25%=1/4：基期4份、增长1份、现期5份。

### 适合
- 已知现期和增长率求增长量；
- 求基期；
- 选项差距较大。

### 不适合
- 增长率离简单分数远；
- 选项极近；
- 对精度要求高。

## 5. 比重、平均数、倍数统一为“两数之比”

设现期分子 `a`、分母 `b`；两者增长率分别 `ra`、`rb`。

```text
现期比值 = a/b
基期比值 = (a/b) × (1+rb)/(1+ra)
```

因此：

- `ra > rb` → 现期比值比基期高；
- `ra < rb` → 现期比值比基期低。

这个框架统一解释：比重、平均数、倍数、利润率、产销率等“两数之比”。

## 6. 两期比重变化

题目问“上升/下降几个百分点”：

```text
变化百分点 = 现期比重 - 基期比重
```

`ra-rb` 只能先判方向，**不能直接当百分点差**。

Training-001 在这一点出错；Training-002 已做对同类题，目前暂判“生疏而非断层”。

## 7. 增长量比较先用单调性

正增长时：

```text
X = B×R/(1+R)
```

当对象1的现期 `B` 更大、增长率 `R` 也更大时，增长量必然更大，可以直接判断。只有“一大一小”时再精算。

## 8. 综合判断题：低计算量优先

先扫选项：

- 直接读数；
- 趋势；
- 数量级；
- 单步比较；

这些先做。复杂还原、多层比重、精细平均放后。找到确定答案立即停。

# 二、判断推理

## 1. 图推先做“特征门控”

不是从几十条规律中盲扫，而是先看图形长什么样：

```text
元素相同 → 位置
元素相似 → 样式
元素差异大 → 属性 / 数量
明显特殊图形 → 对称 / 曲直 / 封闭 / 一笔画 / 空间
```

### 二级特征
“都是对称图形”通常不是答案本身，还要继续看：

- 对称轴数量；
- 对称轴方向；
- 对称轴与点/线/黑块的位置关系；
- 是否同时中心对称。

## 2. 数量类图推不要机械“点线角面素”全扫

只有图形确实表现出数量变化时才进入数量库。优先关注：

- 交点/切点；
- 直线/曲线；
- 封闭面；
- 部分数；
- 元素种类；
- 一笔画奇点数。

## 3. 定义判断抓“硬要件”

不需要把定义每个词都标记。优先抓能直接排除选项的限制：

- 主体；
- 客体；
- 必须条件；
- 方式；
- 目的；
- 结果；
- 范围。

“必须、仅、通过、为了、导致、在……条件下”通常信息密度高。

## 4. 类比：关系句 → 方向 → 二级辨析

一级关系：

- 全同；
- 并列；
- 种属；
- 组成；
- 功能；
- 工具；
- 因果；
- 场所；
- 材料；
- 语法关系。

多个选项都说得通，再比较：方向、词性、必然/或然、主体类型、具体/抽象。

三词题至少检查 `A-B` 与 `B-C` 两层关系；必要时再看 `A-C`。

## 5. 翻译推理只认标准逻辑

```text
如果A，那么B：A→B
只有A，才B：B→A
A→B 等价于 ¬B→¬A
```

可以推出：

- 肯前 → 肯后；
- 否后 → 否前。

不能推出：

- 肯后；
- 否前。

老师口诀与标准逻辑冲突时，以逻辑规则为准。

## 6. 分析/排列推理：强约束优先 + 落表

把条件分三类：

1. **绝对条件**：甲在第3位；
2. **相对条件**：甲在乙前；
3. **绑定/互斥**：甲乙相邻、甲不与丙同组。

先绝对，后相对，再绑定。实体多、条件多时马上画“人×位置/组别”简表；选项给完整方案时，优先代入。

## 7. 加强削弱：先找论证缺口

### 固定动作

1. 写出结论；
2. 写出核心论据；
3. 问“从论据到结论缺了什么”；
4. 先排无关项；
5. 再比较相关选项的力度。

### 常见攻击/支持位置

- 搭桥或拆桥；
- 直接结果证据；
- 另有他因；
- 因果倒置；
- 有因无果/无因有果；
- 样本代表性；
- 实验设计；
- 作用机制。

**没有“某一种选项永远最强”的万能排序。**

Training-002 Q10：结论是“混合办公是有效运营模式”，A“辞职率下降”直接增加运营有效性证据；B“晋升机会均等”更多说明公平/无歧视，相关性较弱。

## 8. 因果论证五问

看到“A导致B”时：

1. 会不会 B→A？
2. 会不会 C 同时导致 A 和 B？
3. 有没有 A 但没有 B？
4. 有没有 B 但没有 A？
5. 是否存在合理机制/实验支持 A→B？

# 三、言语理解

## 1. 先判题型，避免“一套中心句打天下”

至少分：

- 主旨/意图/标题；
- 细节；
- 词句理解；
- 语句填空；
- 下文推断；
- 语句排序；
- 逻辑填空。

不同题型的阅读目标不同。

## 2. 主旨题：结构词只是信号

“但是、因此、甚至、应该”等很重要，但不能机械理解为“后面永远是答案”。

稳定流程：

```text
找主题词
→ 划结构
→ 区分观点与例子/背景
→ 找承担结论功能的句子
→ 比较选项主体/范围/程度/逻辑
```

## 3. 意图题：不要自动选对策

只有文段真的形成“问题/风险 → 分析 → 行动必要性”时，对策才优先。

如果文段只是解释一种现象/机制，正确答案通常仍是作者的解释性观点，而不是你自己推出来的政策建议。

## 4. 逻辑填空：语境先于词汇

```text
上下文关系
→ 推空格语义方向
→ 固定搭配
→ 词义侧重
→ 程度/褒贬/对象
→ 代入
```

多空题优先从差异最大、最容易定位的一空突破。

## 5. 语句排序：从选项入手

首句不优先：

- 指代不明；
- 关联词后半；
- 具体补充；
- 总结句。

再找强捆绑：

- 指代；
- 重复词；
- 时间；
- 因果；
- 转折；
- 概念定义→解释。

## 6. 二选一：比较四维度

- 主体；
- 范围；
- 程度；
- 逻辑关系。

比反复阅读全文更有效。

# 四、数量关系

## 1. 数量速度的第一来源是“识别路径”

每题先问：

```text
能代入吗？
有整除/奇偶/余数吗？
能赋值吗？
是标准模型吗？
方程是否一步可解？
能枚举吗？
```

如果方法路径仍不清晰，就先后做。具体止损秒数以后用个人整卷数据确定。

## 2. 代入排除

高适配：

- 年龄；
- 余数；
- 多位数；
- 不定方程；
- 选项给成组数据；
- 问最大/最小。

技巧：

- 最大从大项代；
- 最小从小项代；
- 先用整除/奇偶排；
- 优先代计算最省的项。

## 3. 数字特性

有数学依据的快筛：

- 整除；
- 奇偶；
- 余数；
- 尾数；
- 因数/倍数。

**不包括“答案分布规律蒙题”**。

## 4. 赋值法

- 工程：总量取时间最小公倍数；
- 利润：成本常设100；
- 浓度：总量/溶质设方便数；
- 比例：按份数整数化；
- 几何比例：长度/面积按比例赋值。

前提：题目只关心比例、效率、相对关系，允许缩放。

## 5. 工程

```text
总量 = 效率 × 时间
```

给多个完成时间时，把总量设为时间的最小公倍数，效率立即整数化。

## 6. 行程

核心只保留：

```text
S=vt
相遇：路程和=(速度和)t
追及：路程差=(速度差)t
流水：v顺=v船+v水；v逆=v船-v水
```

优先画时间线/路程线，避免把“同时出发”“先后出发”“往返”混在脑子里。

## 7. 概率

先判事件结构：

- 分类且互斥 → 加；
- 分步且独立 → 乘；
- 至少一次 → `1-P(一次都没有)`；
- 不放回 → 每一步总数变化。

Training-001 的概率错题纳入 EP-003。

## 8. 排列组合

先问“顺序是否重要”：

- 重要 → 排列；
- 不重要 → 组合。

再看限制：

- 相邻 → 捆绑；
- 不相邻 → 插空；
- 至少/至多 → 补集；
- 相同元素分配 → 隔板（先确认是否允许0）。

## 9. 最值/保证

看到“至少几次保证……”：

```text
构造最大的不满足情况 + 1
```

这是抽屉/最不利原则的核心。

# 五、广东科学推理

## 1. 实验题三变量

- 自变量：人为改变什么；
- 因变量：观察/测量什么；
- 控制变量：其他应保持不变的条件。

若同时改变两个关键条件，一般不能把结果归因于其中一个。

## 2. 图像题四步

1. 横轴是什么；
2. 纵轴是什么；
3. 单位是什么；
4. 斜率/面积/拐点在该模型里代表什么。

## 3. 物理选择题优先用三种检查

- 守恒：能量/质量/电荷等；
- 比例：变量变几倍，结果如何；
- 极限：把某变量设到0或很大，看选项是否仍合理。

# 六、明确淘汰或降级的方法

## 直接淘汰

- 答案分布规律蒙题；
- 转折后必重点；
- 意图题必选对策；
- 加强削弱固定万能强度排序；
- 图推每题机械扫完整规律库。

## 只做候选，不直接个性化

- 固定模块答题顺序；
- 固定每模块用时；
- “数量永远最后”；
- “资料必须25分钟”；
- 所谓秒杀口诀。

这些都必须等完整卷数据后再决定。

# 七、个人方法升级规则

任何外部技巧只有满足以下路径才进入个人稳定方法：

```text
外部候选
→ 数学/逻辑校验
→ 3–5题专项验证
→ 20题以上混合验证
→ 整卷不误用
→ 进入 personal-methodology.md
```

一次成功不代表方法稳定；速度快但误用率高的方法也不保留。
