# 1. 通用解题工具

## 1.1 代入排除法

适用：

- 问具体数值且选项离散；
- 年龄、利润、比例、工程等可直接验证；
- 方程难列但代入简单。

技巧：

- 优先代中间选项；
- 根据单调性决定向大/向小试；
- 代入前先用整除、奇偶排掉明显不可能项。

## 1.2 数字特性

### 整除

常用：

- 2：末位偶数；
- 3/9：各位和；
- 4：末两位；
- 5：末位 0/5；
- 8：末三位；
- 11：奇偶位和之差为11倍数。

### 奇偶

- 奇±奇=偶；
- 奇±偶=奇；
- 奇×奇=奇；
- 任一因子为偶，积为偶。

### 余数

大数幂/周期题优先找循环周期，不直接展开。

## 1.3 方程法

优先设“最核心未知量”，不要见一个量设一个字母。

- 和差倍比 → 一元方程；
- 多个比例 → 设份数；
- 不定方程 → 结合整数性、整除性、选项。

## 1.4 赋值法

适用于：

- 比例关系；
- 工程效率；
- 浓度；
- 平均速度等。

原则：选一个让各比例变整数的值，减少分数。

# 2. 工程问题

核心：

```text
工作总量 = 效率 × 时间
```

## 2.1 给完成时间

若甲 x 天、乙 y 天完成：

可设总量为 `LCM(x,y)`，则效率直接为整数。

## 2.2 合作

```text
合作效率 = 各自效率之和
```

若中途加入/退出，分阶段算工作量。

## 2.3 效率比例

只给效率比时直接赋值，如 2:3:5。

---

# 3. 行程问题

核心：

```text
路程 = 速度 × 时间
```

## 3.1 相遇/追及

- 相向：速度和；
- 同向追及：速度差。

```text
相遇时间 = 初始距离 / 速度和
追及时间 = 初始距离 / 速度差
```

## 3.2 往返平均速度

等路程往返：

```text
平均速度 = 2v1v2/(v1+v2)
```

不能直接 `(v1+v2)/2`。

## 3.3 流水行船

```text
顺水 = 船速 + 水速
逆水 = 船速 - 水速
```

# 4. 经济利润

## 4.1 基础关系

```text
利润 = 售价 - 成本
利润率 = 利润/成本
售价 = 成本×(1+利润率)
```

折扣：

```text
实际售价 = 标价×折扣率
```

## 4.2 多次涨跌

连续变化用乘法：

```text
最终 = 原值×(1+r1)×(1+r2)...
```

先涨20%再降20%不回原值：`1.2×0.8=0.96`。

# 5. 排列组合

## 5.1 基础

```text
A(n,m)=n!/(n-m)!
C(n,m)=n!/[m!(n-m)!]
```

先判断：**顺序重要吗？**

- 重要 → 排列；
- 不重要 → 组合。

## 5.2 高频方法

### 捆绑法

必须相邻的元素先捆成一个整体。

### 插空法

要求不相邻时，先排其他元素，再往空位插。

### 分类加法、分步乘法

- 不同互斥情况 → 加；
- 连续完成多个步骤 → 乘。

### 反面法

“至少一个”常用：

```text
总情况 - 一个都没有
```

# 6. 概率

Training-001 Q6 属于这一模块。

## 6.1 基本概率

```text
P = 有利情况数 / 总情况数
```

## 6.2 独立事件

连续都发生：

```text
P(A且B)=P(A)×P(B)
```

例如某人每题答对概率 p，则连续两题全对：

```text
p²
```

连续两题全错：

```text
(1-p)²
```

两个独立对象再同时满足条件，继续相乘。

## 6.3 至少一次

```text
P(至少一次) = 1 - P(一次都没有)
```

## 6.4 恰好 k 次

独立重复试验：

```text
C(n,k) p^k (1-p)^(n-k)
```

考试中一般只对小 n 直接用，不需要机械背复杂概率模型。

# 7. 容斥原理

## 7.1 两集合

```text
A∪B = A+B-A∩B
```

## 7.2 三集合

```text
A∪B∪C
= A+B+C
-AB-AC-BC
+ABC
```

若题目只问“至少参加一个”，画文氏图常比硬背公式稳。

# 8. 最值问题

## 8.1 最不利原则

“至少……才能保证……”：先考虑最倒霉的情况，再 +1。

典型：抽屉/袜子/颜色/至少同类。

## 8.2 和定最值

总和固定，要让某项最大/最小：把其他项压到允许的边界。

注意：是否要求整数、互不相同、正数。

---

# 9. 浓度问题

```text
溶质 = 溶液×浓度
```

混合后：

```text
总溶质 = 各部分溶质之和
总浓度 = 总溶质/总溶液
```

只加水：溶质不变；蒸发水：溶质不变。

# 10. 几何问题

## 10.1 高频公式

- 三角形：`S=1/2×底×高`；
- 矩形：`ab`；
- 圆：`πr²`；
- 圆周：`2πr`；
- 圆柱体积：`πr²h`；
- 棱柱体积：`底面积×高`。

## 10.2 相似/比例

相似图形：

- 长度比 k；
- 面积比 k²；
- 体积比 k³。

# 11. 周期问题

先找周期 L，再算：

```text
目标序号 mod L
```

余数为0表示落在周期最后一个位置。

日期/星期题也可转成 mod 7。
