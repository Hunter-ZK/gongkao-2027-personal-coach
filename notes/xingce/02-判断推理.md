# 1. 判断推理总流程

拿到题先问：

1. **图形？** → 图推；
2. **词与词？** → 类比；
3. **给定义找例子？** → 定义；
4. **如果/只有/所有/有些/真假/排序？** → 翻译或分析推理；
5. **论据→结论，问加强削弱/前提/解释？** → 逻辑论证。

不同子题型不要混方法。

# 2. 图形推理

## 2.1 思考顺序

你的旧笔记用“定性→定量→位置→样式→特殊→立体”展开，这个框架继续保留。

建议考场检索顺序：

1. **位置**：旋转、翻转、平移；
2. **样式**：叠加、去同存异、黑白运算；
3. **属性**：曲直、开闭、对称；
4. **数量**：点、线、角、面、素、部分数；
5. **特殊元素**：箭头、小黑点、功能点；
6. **空间**：相对面、相邻面、公共点、视图、截面、拼合。

这不是绝对顺序。真正的原则是：**先看最显眼的图形特征，不要机械从第一项扫到最后一项。**

## 2.2 位置规律

### 平移

观察：

- 元素是否按固定步长移动；
- 顺/逆时针；
- 行列循环；
- 多元素是否分别移动。

### 旋转与翻转

- 旋转：图形方向变化但“手性”不变；
- 翻转：镜像关系，左右/上下颠倒；
- 可用不对称小特征做锚点。

## 2.3 样式规律

常见：

- 相加/叠加；
- 求同；
- 求异；
- 黑白叠加运算；
- 元素遍历。

遇到九宫格优先横看/竖看，再看米字或整体。

## 2.4 属性规律

### 对称

看：

- 轴对称/中心对称；
- 对称轴方向；
- 对称轴数量；
- 对称轴与图形元素关系。

### 曲直/开闭

适用于图形组成差异明显但数量不好找的题。

## 2.5 数量规律：点线角面素

### 点

常数：交点、切点、端点、特殊点。

### 线

- 直线/曲线数量；
- 线段数；
- 笔画数。

### 一笔画

[统]

欧拉路径判断：

- 连通图中，奇点数为 `0` 或 `2` → 可以一笔画；
- 奇点数大于 `2` → 不能一笔画。

### 面

封闭区域数量，注意“外面”通常不算图形内部面。

### 角

重点数直角、锐角、特殊角，先看题目图形是否明显出现角的变化。

### 素

元素种类数、元素总数、某类元素个数。

## 2.6 空间重构

### 六面体/展开图

- 相对面永不相邻；
- 公共边、公共点关系不能变；
- 不要凭脑内旋转硬想，优先用相邻关系排除。

### 截面

看“刀能不能同时穿过这些面/棱”，先排除不可能连接关系。

# 3. 类比推理

你的旧笔记四大关系继续保留：**语义、集合、对应、语法**。

## 3.1 两词题

先造一句最硬的关系句，再去套选项。

优先级：

1. 逻辑硬关系；
2. 关系方向；
3. 必然/或然；
4. 主体是否一致；
5. 词性/感情色彩等二级辨析。

## 3.2 三词题

这是 Training-001 Q2 暴露的问题。

三词题不能只看 A-B，要同时检查：

- A 与 B；
- B 与 C；
- A 与 C；
- 三者的角色结构是否一致。

**规则：先构造完整句子，不做“两个词差不多就选”。**

## 3.3 集合关系

- 全同：A就是B；
- 种属：A是一种B；
- 组成：A是B的一部分；
- 并列：A与B属于同一上位概念；
- 交叉：有的A是B，有的A不是B。

## 3.4 对应关系

高频：

- 工具—功能；
- 材料—成品；
- 职业—对象/场所/工具；
- 原因—结果；
- 行为—目的；
- 条件—结果；
- 时间先后；
- 属性—对象。

## 3.5 语法关系

当逻辑关系弱时看：

- 主谓；
- 动宾；
- 偏正；
- 并列；
- 词性对应。

# 4. 定义判断

## 4.1 核心做法

你的旧笔记抓“被定义词、主客体、引导内容、解释说明”，继续保留。

读定义时优先圈：

- 主体；
- 客体；
- 条件；
- 方式；
- 目的；
- 结果；
- 时间/范围限定。

## 4.2 选项匹配

- 出现**硬性条件冲突**，直接排；
- 定义中多个条件通常是“且”，不能只满足一个；
- 不要用生活常识替换题干定义；
- 多定义题先确定题目问的是哪个定义，再匹配。

## 4.3 快速策略

如果四个选项中三个都明显缺同一关键条件，优先检查剩余项，不需要逐字逐句完全证明。

# 5. 翻译推理

## 5.1 基本命题

### 如果 A，那么 B

```text
A → B
逆否：¬B → ¬A
```

**不能推出**：

- `B→A`（肯后）；
- `¬A→¬B`（否前）。

### 只有 A，才 B

```text
B → A
```

“只有A才B”里，A是B的必要条件。

### A且B

真：两者都真。  
否定：

```text
¬(A且B) = ¬A 或 ¬B
```

### A或B

至少一个真。  
否定：

```text
¬(A或B) = ¬A 且 ¬B
```

### 要么A要么B

排他或：恰好一个为真。

### 除非A，否则B

常用翻译：

```text
¬A → B
```

等价逆否：

```text
¬B → A
```

## 5.2 所有/有些

- 所有 A 都是 B → `A⊆B`；
- 有些 A 是 B → 至少一个交集；
- “所有A都是B”的否定 → “有些A不是B”；
- “有些A是B”的否定 → “所有A都不是B”。

注意：“有些A是B”可以推出“有些B是A”，但不能推出所有关系。

---

# 6. 真假推理

## 6.1 先找矛盾

常见矛盾：

- A 与 ¬A；
- 所有A是B ↔ 有些A不是B；
- 有些A是B ↔ 所有A不是B；
- `A→B` ↔ `A且¬B`；
- `A或B` ↔ `¬A且¬B`；
- `A且B` ↔ `¬A或¬B`。

如果题目给“一真其余假/一假其余真”，先锁矛盾对，再判断剩余句。

# 7. 分析推理 / 组合排列

Training-001 Q5 属于这一类。

## 7.1 什么时候必须落纸

出现以下任一情况，不要全靠脑推：

- 人/物 ≥ 4；
- 多个名次/位置；
- “如果…那么…”和排除条件交叉；
- 问“不可能/一定/错误”的选项。

## 7.2 常用方法

### 表格法

主体 × 属性/位置，确定的先填，不能的打叉。

### 排序法

把“大于/早于/高于”转成链：

```text
A > B > C
```

### 代入法

题目问“可能/不可能”，且选项给出完整方案时，直接代入往往最快。

### 假设法

条件无法直接推出时，假设某一对象在某位置，看是否产生矛盾。

### 极值/唯一入口

先找约束最强的人或位置，例如“只能”“必须”“恰好”“不与任何…”。

# 8. 逻辑论证

## 8.1 先压缩成三件事

1. 论据是什么；
2. 结论是什么；
3. 论据到结论中间缺什么。

不要被故事背景带走。

## 8.2 加强

常见强度从高到低需结合题目判断：

- 建立论据与结论的必要联系；
- 排除关键他因；
- 补充支持性证据；
- 举例/个案通常较弱。

## 8.3 前提假设

两种核心：

### 搭桥

论据谈 A，结论谈 B，中间缺 `A→B`。

### 必要条件

用**否定代入法**：把选项否掉，如果结论直接崩掉，该选项很可能是必要前提。

Training-001 Q8 你答对，说明这类基础仍在。

## 8.4 削弱

### 因果论证

题干：A 导致 B。

常见削弱：

- 因果倒置：其实 B 导致 A；
- 另有他因：C 才导致 B；
- 有因无果：A 出现但 B 没出现；
- 无因有果：没有 A 也出现 B；
- 样本/实验设计不能支持推广。

### 对比实验

先看：

- 两组初始条件是否可比；
- 是否唯一变量不同；
- 是否有足够样本；
- 是否把相关性当因果。

### 一般论证

最强削弱通常直接打击“论据→结论”的链条，不是只指出无关副作用。

## 8.5 解释现象

目标不是证明谁对，而是找一个事实让表面矛盾可以同时成立。

# 9. 判断推理选项规则

- 题目问“最能”，要比力度，不是“能”就选；
- 新概念、强限定词、主体变化是高频陷阱；
- 论证题优先看与结论直接相关的选项；
- 分析推理题若选项完整，代入往往比硬推更快；
- 图推卡 45–60 秒还没有规律，应先跳，不要在一个图上赌整套节奏。
