# 1. 资料分析：从“背公式”转向“识别—列式—选精度”

## 1.1 多个学习者整理花生十三课程时出现的共同结构

公开的课程整理/学员笔记通常不是把资料分析做成一张公式表，而是拆成：

`速算 → 增长体系/ABRX → 比重 → 比较 → 平均/倍数 → 特殊考点 → 综合`

这说明资料分析真正需要恢复的是**题型地图**。

### 候选动作 A｜看到题先完成四个识别

```text
1. 时间：现期还是基期？同比还是环比？
2. 主体：哪个对象？部分还是整体？
3. 问法：量 / 率 / 比重 / 平均 / 倍数 / 差值？
4. 选项：差距大不大？需要精算到什么程度？
```

其中第4步非常重要：速算不是“永远少算几位”，而是**选项差距决定精度**。

## 1.2 学员复盘中高频出现的速算观念

公开整理内容常把加减乘除分别训练：

- 加法：尾数/高位叠加；
- 减法：基准值/分段；
- 乘法：小分互换、拆分、放缩；
- 除法：截位、拆分、放缩。

### 本仓库的限制条件

这些方法不按“背口诀”使用，而要问：

- 选项尾数真的能区分吗？
- 放缩后误差方向是否明确？
- 两个候选答案是否过近？
- 题目问的是“约”还是精确范围？

**候选方法必须同时记录适用条件。**

## 1.3 份数/百化分真正的用途

不是为了炫技，而是把难除法转成比例。

例如增长率接近 `1/n`：

```text
基期 : 增长量 : 现期 ≈ n : 1 : n+1
```

看到 20%、25%、16.7%、12.5% 等值，应逐渐形成对应分数感。

### 学员经验的正确使用方式

网络上有人通过大量资料题训练，把20题压到25分钟左右；这只能说明“速度是可训练的”，**不能把25分钟直接设成当前个人达标线**。当前用户应先测恢复后的稳定速度。

# 2. 判断推理：图形不是“猜规律”，而是特征驱动检索

## 2.1 图推的公开学习笔记高度一致的一点

刘文超课程相关公开学员笔记常用：

```text
元素相同 → 优先位置
元素相似 → 优先样式
元素明显不同 → 属性/数量
数量明显 → 点线面素角
```

这是**检索入口**，不是死顺序。

## 2.2 位置规律

看到元素基本不变、只换位置：

- 平移：方向 + 步数；
- 旋转：方向 + 角度；
- 翻转：横轴/纵轴；
- 内外圈：分别观察运动。

### 候选动作

先比较相邻两图“变化了什么”，不要一上来数点线面。

## 2.3 数量规律

常见检索维度：

`点 → 线 → 面 → 素 → 角`

其中一笔画：

```text
图形连通 + 奇点数为0或2 → 可一笔画
```

但要避免把“一笔画”当万能考点；先确认图形确实出现明显线条连接特征。

## 2.4 类比：关系要写成一句话

公开教学中不同老师表达不同，但比较稳的做法是：

1. 先判断一级关系：语义/逻辑/对应/语法；
2. 再看方向；
3. 多选项都通时做二级辨析；
4. 三词型至少核对两组关系。

### 个人提醒

Training-001类比错1题，但Training-002两道类比均正确，因此暂不下“类比弱”的结论。

## 2.5 论证：不要被“听起来是好事”的选项骗

加强/削弱真正问的是：

> 这个选项出现以后，**结论变得更可能为真还是更不可能为真？**

Training-002 Q10是典型提醒：

- “晋升机会均等”是好事，但不直接证明“混合办公是有效运营模式”；
- “辞职率下降”直接补充有效运营的结果证据，相关性更强。

以后先判断**相关性**，再比较**力度**。

# 3. 言语理解：恢复结构，不恢复“玄学语感”

## 3.1 阿里木江公开课程与学员思维导图给出的启发

公开课程按以下方式拆题：

- 中心理解：转折、因果、条件、并列、主题词、行文脉络；
- 标题/细节/词句；
- 排序/填句/接语；
- 逻辑填空：转折、递进、并列、解释等语境关系。

社区出现“十几分钟快速复习思维导图”的内容，说明对有旧基础的人，**先恢复框架比重新听几十小时基础课更符合当前需求**。

## 3.2 中心理解候选流程

```text
看问法
→ 找文段主题
→ 划层次
→ 找重点关系（转折/因果/问题-对策/并列）
→ 对照选项范围、主题、语气
```

### 对策不能机械优先

“文中出现应该/需要”不等于答案必然是对策。还要判断：

- 对策是不是作者真正结论；
- 问的是主旨还是细节；
- 选项有没有偷换主体、扩大范围。

## 3.3 逻辑填空候选流程

```text
先看语境逻辑
→ 找对应词/关联词
→ 再辨析词义、搭配、程度、感情色彩、对象
→ 最后代入
```

禁止第一步就凭“这个词读起来顺”。

# 4. 数量关系：目标不是“所有题都会”，而是建立题型收益判断

## 4.1 多个公开体系反复出现的基础工具

- 赋特殊值；
- 方程；
- 比例；
- 代入排除；
- 整除/奇偶/余数；
- 枚举。

这些工具比记住大量“秒杀口诀”更稳定。

## 4.2 考场第一问不是“怎么做”，而是“值不值得做”

建议形成决策链：

```text
15秒内能识别模型吗？
    ↓ 是
有没有明显短路径（代入/整除/赋值/方程）？
    ↓ 是
继续

如果识别困难 + 条件复杂 + 计算量大
→ 标记后做
```

## 4.3 当前个人最重要的数量标签

以后每道数量题不只记对错，还要记：

- `S1 秒识别-快算`
- `S2 识别快-计算慢`
- `S3 识别慢-会做`
- `S4 建模失败`
- `S5 应放弃却纠缠`

Training-001/002累计4/5，但用户明确感觉数量更花时间，所以现阶段**速度结构比正确率更有信息量**。

# 5. 模考复盘：陈怀安类内容适合什么时候用

陈怀安近年持续做国考/省考模考复盘，并按资料、数量、判断、言语等模块拆开，也有第一视角。

这种内容的价值主要在 Phase 1/2：

- 高手看到题后先判断什么；
- 如何选择短路径；
- 什么时候跳题；
- 一整套卷时间怎么分配；
- 复盘时如何把一道题提炼为方法。

### 当前阶段不做什么

不把模考复盘里某一次的顺序和时间直接复制成个人策略。

等广东90分钟基线完成后，再对照第一视角和模考复盘做个人时间结构优化。

# 6. 学员笔记怎么进个人知识库

社区/学员笔记只提取三类内容：

### A. 有操作性的结构

例如：某模块如何划分、复习顺序如何压缩。

### B. 高频误用提醒

多个学习者反复踩的坑，可以提高警惕，但仍要真题验证。

### C. 训练方式

例如“思维导图快速恢复 + 真题验证”是否比完整重听更高效。

不纳入：

- 纯老师评价；
- “必上岸”“必提多少分”；
- 无适用条件的秒杀口诀；
- 单次考试偶然经验。

# 7. 本文件后续如何更新

每研究一个老师/学员整理，不另开无限多文件，而是：

1. 先记录在 `workbench/research-dashboard.md`；
2. 有明确可执行价值 → 写到本文件；
3. 属于某一模块稳定方法 → 合并到 `01~06` 正文；
4. 用户真题反复验证有效 → 升级到 `progress/personal-methodology.md`；
5. 被真题证伪或个人使用成本高 → 标记限制/淘汰。
