# 体验升级 v2｜一次性交付说明

> 用户于实施阶段明确要求：不再分 PR0/PR1/PR2/PR3 逐阶段等待，改为一次性完成全部改造并统一验证。

## 本次统一交付范围

一次性覆盖原任务书 A/B/C/D 全部范围：

1. 入口之后的内容决策：知识推荐、推荐题组、中断恢复、后台导入、自动同步；
2. 笔记体验：情形级虚拟切分、唤醒/方法/出处三形态、多师分歧与采用状态、阅读排版、数据带、5题验证、扩写层；
3. 信息密度：题库/错题/复训/推荐列表密行、极简做题页、默认展开规则、禅模式；
4. AI 诊断：固定结构、Prompt 约束、可反驳、异步不阻塞；
5. 保护措施：不改数据库 schema、不改原文字符、不自编题、保留原文快照与字符级校验。

## 统一验收

本次不再以阶段人工 Gate 作为提交条件，最终只接受整体验收：

- React type-check/build 通过；
- Python tests 通过；
- Python compile 通过；
- 既有视觉/内容 lint 通过；
- 三平台 Workbench CI 全绿；
- 正式笔记原文快照逐文件校验，非空白字符差异数必须为 0；
- `frontend_dist` 与最终前端源码同步；
- 合并后 `main` 再次通过三平台 CI。

原 `PR1-PR3实施边界.md` 仅保留为历史规划记录，不再约束交付节奏。
