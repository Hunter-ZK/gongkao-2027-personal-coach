# PR1–PR3 实施边界

> 由于用户提供的 v2 说明书正文缺少原文所引用的“第 7 节”，PR0 按依赖关系补齐并冻结后续实施边界。
> 
> 原则：每个 PR 只解决一组用户可验证的问题；不把所有改造一次性塞进一个大 PR。

## PR0｜规则与边界（当前）

只提交文档，不提交业务代码。

交付：
- `改造清单.md`
- `切分规则表.md`
- `笔记原文边界说明.md`
- `切分校验规范.md`
- `PR1-PR3实施边界.md`

Gate：用户确认切分规则后，才允许 PR2 触碰正式笔记切分。

---

## PR1｜入口决策 + 信息密度 + 通用作答会话

### 目标

先把“进入模块后还要自己挑”和“做题中断丢状态”解决掉，让应用日常可用性先提升。

### 范围

#### 1. 知识首页推荐壳
- `/knowledge` 默认展示 5–8 条推荐笔记；
- 推荐理由使用现有错题、错误模式、计划、阅读历史；
- 阅读历史从 PR1 上线后开始记录，历史不伪造；
- “浏览全部笔记”进入现有完整目录树；
- PR1 不切正式笔记正文。

#### 2. 训练首页推荐题组
- `/trainings` 默认展示 3–5 组已配题组；
- “自选题目”进入原题库；
- 复用 question_bank / question_attempt / review 调度；
- 不生成新题。

#### 3. 通用作答会话
- 把题库题真正接入可作答流程；
- 保存题级状态；
- 每题 + 每15秒自动保存；
- 支持暂停并退出；
- 支持关闭浏览器后恢复；
- 状态放 `setting.value_json`，不加表。

#### 4. 列表密行化
- 题库；
- 错题；
- 复训候选；
- 推荐笔记。

首屏硬指标：≥8 条。

#### 5. 做题页净化
作答时只保留：
- 题干+选项；
- 剩余时间；
- 暂停并退出。

#### 6. 禅模式升级
- 无彩色；
- 无徽标/进度条；
- 中性标签页标题；
- 正文衬线体；
- 工作文档观感。

### 明确不做

- 不批量切笔记；
- 不生成扩写；
- 不改 AI 诊断 schema/Prompt；
- 不改 PDF 后台流程；
- 不改同步触发时机。

### 验收

1. 知识页首屏 5–8 个推荐项；
2. 训练首屏 3–5 个推荐题组；
3. 题库题可直接作答；
4. 中断恢复误差≤1题；
5. 密行首屏≥8；
6. 做题页无多余卡片/统计；
7. 禅模式肉眼像工作文档；
8. 三平台 CI 全绿。

## PR2｜笔记结构重构 + 方法验证 + 扩写层

### 前置 Gate

必须满足：
- `切分规则表.md` 已确认；
- 正式原文快照完成；
- 字符级校验脚本/测试先写好。

### 范围

#### 1. 一次性全模块情形级切分
- 采用 `parent_slug::unit_id`；
- 全模块一次完成，不做试点分批；
- 只剪切和归位原文；
- 原文非空白字符差异必须为 0。

#### 2. 三层阅读
- 唤醒层；
- 方法层；
- 出处层。

#### 3. 阅读版式
- 单栏；
- 60–70字行宽；
- 17–18px；
- 1.7 行高；
- 方法层不折叠；
- 只有出处层折叠。

#### 4. 多师并列与采用状态
- 保留老师/Skill 署名与分歧；
- 用户指定“我采用”；
- 支持“已弃用”；
- 数据依据来自真实作答。

#### 5. 笔记数据带
- 做过题数；
- 正确率；
- 错误复发；
- 最近验证。

#### 6. 按这个方法练 5 题
- 复用 PR1 通用作答会话；
- 只用题库真题；
- 训练结束回到原笔记；
- 形成有效/无效/待定验证记录。

#### 7. 扩写层
- 六种固定类型；
- 原句 hash 锚定；
- 先找原始讲义，再 AI；
- AI 生成标未验证；
- 用户可采纳/删除；
- 删除写日志；
- 批量范围仅复发≥2或做题≥10；
- 其他按需/失败触发。

#### 8. 必须生成两份验收文档
- `切分比对报告.md`；
- `切分结果清单.md`。

### 明确不做

- 不改数据库 schema；
- 不自编题；
- 不把 AI 扩写写进原文；
- 不在 PR2 重构 AI 诊断主流程。

### 验收

1. 差异字符数严格 0；
2. 所有情形 ID 唯一；
3. 例题跟随方法；
4. 唤醒层无扩写；
5. 方法层默认展开；
6. 出处层默认折叠；
7. 扩写来源一眼可辨；
8. 5题验证链闭环；
9. 三平台 CI 全绿。

## PR3｜AI 诊断 + 苦役后台化收口

### 目标

让“做题反馈”更快、更可纠正，并把 PDF/同步从学习主动线移开。

### 范围

#### 1. 固定 AI 诊断结构
- 一句话结论；
- 新7类错因；
- 识别信号；
- 考场动作；
- 止损线；
- 关联笔记；
- 验证任务；
- 置信度。

存储继续使用现有文本/JSON 能力；旧记录兼容读取。

#### 2. Prompt 收口
- 先检索正式笔记；
- 识别信号必须来自题干原词句；
- 具体秒数；
- 不确定=未验证；
- 首屏结论+动作≤60字。

#### 3. 可反驳
- 认同；
- 错因不对；
- 一次性失误；
- 用户选择覆盖 AI；
- 修正结果进入后续诊断上下文。

#### 4. 深诊断异步
- 作答立即返回对/错、正确答案、极短结论；
- 深诊断后台跑；
- AI 无 key/失败/超时不阻塞下一题；
- 徽标提示新诊断。

#### 5. PDF/校对后台化
- 上传后立即回到学习；
- 后台解析；
- 徽标显示待校对；
- 不弹窗打断。

#### 6. 自动同步
- 启动自动 pull；
- 有效学习会话结束自动 push；
- 只有冲突提示；
- 手动按钮收进设置。

### 验收

1. AI 不可阻塞答题；
2. 首屏诊断足够短；
3. 人工错因能覆盖 AI；
4. 一次性失误不进入错误模式；
5. AI 失败有明确文案，无空白/死转圈；
6. PDF 后台处理时可继续学习；
7. 同步正常时无感，冲突才打扰；
8. 三平台 CI 全绿。

## PR 顺序不可跨越

`PR0 → 用户确认规则 → PR1 → 实际使用反馈 → PR2 → 实际使用反馈 → PR3`

任何后续需求如果会改变已冻结边界，应先更新本文件，不在代码 PR 中临时扩大范围。
