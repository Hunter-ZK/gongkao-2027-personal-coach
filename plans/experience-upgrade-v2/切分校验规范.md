# 笔记切分校验规范

> 目标：批量切分后，证明“正式原文只被剪切与归位，没有被改写”。

## 1. 校验对象

基准：
`notes/_snapshot_before_split/formal_nodes/`

新版本：
切分后的正式原文层。

不参与比较：
- YAML front matter；
- 情形 ID、标题、目录、推荐理由；
- 唤醒层派生信号；
- 数据带；
- 多师采用状态；
- 扩写层；
- 用户批注；
- JSON 状态文件。

## 2. 字符归一化

为了只排除排版移动造成的差异，比较前允许执行且只能执行：

1. 删除空格、Tab、CR/LF 等 Unicode 空白字符；
2. 不删除标点；
3. 不统一全角/半角；
4. 不统一中文/英文引号；
5. 不统一数字或公式符号；
6. 不做 Unicode 字形替换；
7. 不做 Markdown 语义转换。

因此：

`非空白字符差异数 = 0`

才算通过。

## 3. 顺序规则

- 每个父节点保存原始片段的 source-order 序号；
- 校验时按原始 source-order 拼接所有情形原文；
- 一个原文字符只能属于一个原文片段；
- 多个情形需要共享同一说明时，用 reference pointer，不复制原文字串。

这样同时防止：
- 漏字；
- 多复制一份；
- 段落次序错乱；
- 改标点后侥幸通过。

## 4. 必须生成的 `切分比对报告.md`

至少包含：

```text
正式节点总数：N
快照非空白字符数：A
切分后非空白字符数：B
新增原文字符数：0
删除原文字符数：0
修改原文字符数：0
重复原文字符数：0
差异字符数：0
结论：PASS
```

并逐节点列出：

| 父节点 | 快照字符数 | 新原文字符数 | 差异 | 结果 |
|---|---:|---:|---:|---|
| data-abrx-base | ... | ... | 0 | PASS |

任何一个节点非 0：整个批量切分失败，不允许合并。

## 5. 必须生成的 `切分结果清单.md`

每个新情形至少列：

| 字段 | 内容 |
|---|---|
| note_id | `parent_slug::unit_id` |
| parent_slug | 原知识节点 |
| 原文来源 | 原文件 + 原始章节/段落序号 |
| 触发信号 | 题干级词句 |
| 第一动作 | 考场动作 |
| 切换/止损 | 回退条件 |
| 唤醒层来源 | 哪些原文片段派生 |
| 方法层原文 | 哪些 source-order 范围 |
| 出处层原文 | 哪些 source-order 范围 |
| 例题归属 | 真题/原讲义例题引用 |

## 6. 失败处理

出现任一情况必须回滚该父节点重切：

- 差异字符数 > 0；
- 同一 source-order 被多个情形复制；
- 原文句子为适应新结构而补写连接词；
- 例题脱离其示范方法；
- 上位框架被错误拆成多个重复正文；
- 扩写文本混入正式原文层。

## 7. 后续自动测试要求

PR2 必须新增测试覆盖：

1. 快照文件存在；
2. 全部正式节点均参与切分或明确标记“无需切分”；
3. note_id 唯一；
4. source-order 不重复、不缺失；
5. 每条情形至少有触发信号与第一动作；
6. 非空白字符差异数严格为 0；
7. 扩写 JSON 不参与原文拼接；
8. “演示”扩写引用的 question id 必须真实存在于题库。
